# 가난한자의 FM (3sec) — 모바일 풋볼 매니저 (매치 엔진 우선 개발)

FM(Football Manager)류 모바일 게임 프로젝트. **경기 시뮬레이션(매치 엔진)을 먼저** 만들고, 실제 축구 규칙·물리·능력치 기반 확률 모델을 검증한 뒤 UI/관리 레이어를 얹는 순서로 진행한다.

## 구조 (pnpm 모노레포)

- `packages/game` — **시즌 레이어**: 12개 가상 구단(20인 스쿼드), 더블 라운드로빈 22라운드, 역할 적합도 기반 자동 선발과 수동 교체(선발↔벤치↔예비), 경기 결과 반영(출장·득점·경고 누적 5장 → 1경기 정지, 퇴장 → 1~2경기 정지, 피로 이월, 부상), 주간 회복, 시즌 종료 후 나이·성장/쇠퇴, 순위표·득점 순위, JSON 저장/불러오기. 사용자 팀만 사람이 지휘하고 나머지 경기는 같은 엔진으로 AI 대 AI로 진행된다.
- `packages/game/src/transfers.ts` — **이적 시장**: 능력·나이 기반 시장 가치(억원), 구단 평판·리그 순위에 따른 예산, 창구(프리시즌·겨울 11~12R 전·시즌 종료 후), 상대 구단 호가(핵심 선수 프리미엄, 16명 이하 구단은 비매), 판매 시 AI 구단 입찰, AI 구단 간 보강 이적.
- `packages/game/src/training.ts`, `contracts.ts` — **훈련·성장·계약**: 주간 훈련(초점 6종 × 강도 3단계)으로 어린 선수는 잠재력까지 성장하고 30대는 피지컬부터 쇠퇴. 선수별 연봉(가치의 8%/시즌)이 매주 예산에서 빠지고, 계약 만료 선수는 재계약(계약금 = 가치 5%×연수)하지 않으면 시즌 후 떠남. AI 구단은 자동 재계약/방출.
- `packages/game/src/cup.ts` — **3sec 컵**: 12구단 단판 토너먼트(평판 상위 4팀 1라운드 부전승 → 8강 → 4강 → 결승). 리그 6·11·16·21라운드 뒤 컵 경기일. 무승부는 승부차기(키커 마무리·침착 vs GK 반사신경). 상금 8강 탈락 4억, 4강 8억, 준우승 15억, 우승 30억. 컵 경고는 리그 징계에 누적되지 않음. 시즌 종료 시 **시즌 결산 화면**(순위·우승·컵·득실·예산 변화·팀 득점왕·유스 승격·하이라이트).
- `apps/viewer` — 시즌 모드 앱: 홈(다음 경기·소식·순위), 스쿼드(포메이션·선발·기본 전술), 순위, 경기(라운드의 6경기가 동시에 진행되며 다른 구장 스코어가 실시간 표시, 기본 **자동 배속**: 골문 근처 3배·중원 20배·중단 40배로 한 경기 약 9분, 폰 가로 모드에서는 경기장이 화면을 채우는 몰입 모드 + 전술·교체 서랍), 결과 화면. 진행 상황은 `localStorage`에 자동 저장.


```
packages/engine   순수 TypeScript 매치 엔진 (의존성 0, 브라우저/모바일/서버 어디서나 실행)
apps/viewer       Vite + Canvas 2D 개발용 관전 뷰어 (재생/배속/디버그 오버레이)
```

### 엔진 설계

- **결정론적 시뮬레이션**: 고정 20Hz 틱, 시드 기반 PRNG. 같은 시드 → 같은 경기 (리플레이/디버깅/서버 검증 가능)
- **좌표계**: 미터 단위, 원점 = 센터 스팟, x = 길이(±52.5), y = 폭(±34), z = 공 높이 (2.5D)
- **공 물리** (`physics/ball.ts`): 중력, 2차 공기저항(k≈0.013), 바운스 반발계수, 잔디 구름저항. 구름 모델은 닫힌 해로 역산 → 패스 속도/도달 시간 정확히 계산
- **선수 운동** (`physics/player.ts`): 가속도·최고속도·회전 제한(민첩성/속도 의존), 피로 누적
- **규칙** (`match.ts`): 골(공 전체가 라인 통과), 스로인/골킥/코너킥, 오프사이드(패스 순간 스냅샷, 자기 진영 예외, 스로인/코너/골킥 예외), 파울/경고/퇴장/PK, 재개 시 9.15m 이격, 킥오프 자기 진영, 전후반·추가시간
- **AI**
  - 오프더볼 (`ai/positioning.ts`): 포메이션 기반 팀 셰이프 + 공 위치 시프트, 대인 마크 배정(위험도 순), 프레싱/체이싱(공 궤적 예측 기반 인터셉트), GK 포지셔닝, 데드볼 배치
  - 온더볼 (`ai/decision.ts`): 유틸리티 AI — 슛/패스/드리블/클리어/홀드 점수화, 패스 레인 안전도(수비수 도달시간 vs 공 도달시간), 능력치(1~20, FM 방식) 기반 실행 오차
- **통계**: 점유율, 슈팅/유효슈팅, xG, 패스 성공률, 코너, 파울, 오프사이드, 카드
- **감독 개입** (`match.requestSubstitution`, `match.setTactics`)
  - 교체: 벤치 7명, 최대 5명, 실제 규칙(Law 3)대로 **경기 중단 시점에 투입**(플레이 중 요청 → 다음 아웃/파울/골 때 적용), 터치라인에서 진입
  - 전술 실시간 변경: 포메이션(역할 유사도 기반 자동 재배치), 멘탈리티, 수비라인, 프레싱, 직접성, 폭 → 포지셔닝·패스 위험 감수·슛 적극성에 반영
  - 피로: 이동거리/스프린트 기반 누적(90분 후 스태미나 7→~70%, 17→~40%), 속도·가속 저하 → 교체 판단 근거
  - AI 감독(상대팀): 60분 이후 피로 선수 교체, 70분 이후 지고 있으면 공격 전환/이기고 있으면 잠그기

## 모바일에서 보기

1. **바로 보기**: 공개된 아티팩트 링크를 휴대폰 브라우저로 열면 하단 탭 레이아웃으로 동작합니다. iOS Safari는 공유 → "홈 화면에 추가", Android Chrome은 메뉴 → "홈 화면에 추가"로 앱처럼 설치할 수 있습니다.
2. **PWA**: `pnpm --filter viewer build` 결과(`apps/viewer/dist`)를 아무 정적 호스팅에 올리면 매니페스트·서비스 워커로 설치형/오프라인 앱이 됩니다.
3. **Android APK**: GitHub Actions의 `Android APK` 워크플로가 push마다 디버그 APK를 빌드해 아티팩트(`3sec-fm-debug-apk`)로 올립니다. Actions 탭 → 최근 실행 → Artifacts에서 내려받아 설치하세요(출처를 알 수 없는 앱 허용 필요). 로컬 빌드: `pnpm --filter viewer android:apk` (Android SDK·JDK 17 필요). Capacitor 프로젝트는 `apps/viewer/android`.
4. iOS 네이티브 래핑은 `npx cap add ios` 후 Xcode에서 빌드(맥 필요).

## 실행

```bash
pnpm install
pnpm dev            # 뷰어 (http://localhost:5173)
pnpm test           # 엔진 유닛 테스트 (물리, 결정론, 규칙)
pnpm sim 20         # 헤드리스 20경기 시뮬레이션 + 통계 요약
pnpm sim 1 --log    # 1경기 이벤트 로그
```

### 3차 캠페인에서 채택된 변경
1. 블록 굴절이 **맞은 부위**에 따라 결정(중앙=되튐, 측면=꺾임, 스침=진행) → 블록 3.8 → 5.0, 코너 ↑
2. 슛 정확도 모델 재설계: 거리 비례 부정확 + 압박/첫터치 시 급격 악화 + **비압박 침착한 마무리는 정밀** → 유효슈팅 6.9 → 9.0
3. 롱슛 비중 ↑(longRangeBase 0.35), 근거리 슛 적극성 조정
4. AI 감독이 **전력 열세를 인지**하면 롱볼·낮은 라인으로 시작; 약한 패서는 압박 시 클리어링 선호 → 전력차 31:3 → 29:4.5
5. 침투 런 중인 동료에게 스루패스 선호, 런 빈도 ↑
6. 퇴장 빈도(2경고 관용 ↑, 직접 퇴장 ↓) → 0.29 → 0.13
7. **1:1 상황**: 스트라이커가 GK까지 몰고 들어가고, GK는 앞으로 나와 각을 좁히며, 라인을 벗어난 GK도 세이브 확률 판정을 거침 (예전엔 22m에서 쏘거나 GK가 그냥 잡음)
8. 드리블 시 가속 제동 제거(캐리 속도 유지), 셰이프 조정 시 1m 이내는 정지(불필요한 잔걸음 제거)
9. 통계 게이트 테스트(`test/stats-gate.test.ts`)와 시나리오 테스트(`test/scenarios.test.ts`: 1:1, 코너킥, 레인 수비수 앞 슛) 추가 — 이후 모든 변경은 이 게이트를 통과해야 함
10. 자연스러움 지표 스크립트(`scripts/naturalness.ts`): 떨림·뭉침·정지·스프린트 비율, 최종3분의1 수비 밀착도
