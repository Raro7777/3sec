## 0. 이 문서의 사용법 & 핵심 규격 5줄 요약

**핵심 규격 5줄**

1. **룩**: 일본 애니메풍 셀 셰이딩(기본 2단 + 국소 3단), 색 선(컬러 트레이스) 외곽선, 7~7.5등신, 밝은 청춘 스포츠물, 12세 이용가.
2. **광원**: 키 라이트 화면 좌상단 45°/45° 고정. 림라이트는 SR 이상에서만(등급 차등의 핵심 수단).
3. **카드**: 3:4, 2048×2732 PNG(알파), 얼굴 중심 (0.50W, 0.30H) 권장, 하단 22%·외곽 6%는 UI/프레임 영역. 로고·번호·엠블럼은 그리지 않고 벡터 후합성.
4. **일관성**: 등급 무관하게 "캐릭터 프롬프트 블록 + 고정 시드"를 기록, SSR·히어로는 캐릭터별 LoRA 추가. 신규 캐릭터는 기존 승인 카드 3장과 비교 보드에서 승인.
5. **양산 단위**: 캐릭터당 카드 1 + 썸네일 1 + 스탠딩(본체+앞머리+표정 4) + SD 토큰 헤어 파츠 1 = 목표 6시간(4~8시간 범위), SSR은 각성 1장 추가.

**가장 먼저 할 3가지**

1. 10절 체크리스트로 **사용할 체크포인트·LoRA 학습 도구·업스케일러의 상용 이용 조건을 확인**하고 부록 B 양식에 기록한다. (라이선스가 막히면 이후 작업이 전부 무효)
2. 3.4절 방법으로 **포지션 5종 포즈 뱅크**(OpenPose 스켈레톤 JSON + PNG)를 먼저 만든다. 42명이 이 뱅크를 재사용한다.
3. 9절 절차대로 **히어로 1명(권장: OH 포지션 SSR)을 시험 제작**하고 시간 기록표를 채워 GDD 9.6 물량 추정을 보정한다.

## 1. 아트 디렉션 요약

### 1.1 한 줄 정의

> "체육관 조명 아래, 땀보다 웃음이 먼저 보이는 청춘 스포츠 애니메이션의 한 컷."

| 항목 | 정의 |
|---|---|
| 화풍 | 일본 애니메풍(TV 애니메이션 키비주얼 급 셀 채색), 가챠 수집형 주류 문법 |
| 톤 | 밝고 채도 높은 청춘 스포츠물. 고채도 원색이 아니라 "맑은" 중고채도. 어둡거나 처절한 연출 금지(피로/좌절 표정도 "다음엔 이긴다" 톤) |
| 체형 | 건강한 운동선수. 어깨·허벅지에 가벼운 근육 표현, 과장된 가슴·허리 곡선 금지 |
| 연령 인상 | 모든 선수는 **설정상 성인 프로 선수(18세 이상)**. 얼굴은 청년(대학생~20대 초중반) 인상으로 통일. 아동·소녀형 얼굴/체형 금지 (12세 이용가 및 여성 스포츠 소재 대외 이미지 보호) |
| 카메라 | 카드: 다이내믹(로우앵글·투시), 스탠딩: 아이레벨 정면 3/4, 토큰: 정면 |

### 1.2 Do / Don't

| Do | Don't |
|---|---|
| 동작의 순간(공 접촉 직전·직후) | 정지된 기념사진 포즈(카드에서) |
| 땀방울 소량(얼굴·목 1~3개), 상기된 볼 | 젖어 비치는 옷, 과다한 땀 |
| 무릎 보호대·발목 양말·배구화(배구다움 식별자) | 맨발, 하이힐, 액세서리 과다 |
| 밝은 체육관 조명, 코트 바닥 반사 | 어두운 무드, 핏빛·잿빛 톤 |
| 표정의 의지·집중·기쁨 | 수줍음·유혹·눈물 클로즈업(팬서비스 문법) |

### 1.3 캐릭터 구분 3중 원칙 (GDD 9.1)

42명이 리스트에서 서로 구분되어야 한다. 아래 3층을 **모두** 다르게 한다.

| 층 | 수단 | 규칙 |
|---|---|---|
| 1. 실루엣 | 헤어 형태·길이, 키 | 같은 구단 7명 안에서 헤어 길이 카테고리 중복 최대 2명, 동일 (길이+색) 조합 금지 |
| 2. 컬러 | 헤어 컬러, 눈 컬러 | 헤어 팔레트 16색(2.7절) 중 선택. 비현실 색(핑크/블루/그린/퍼플)은 구단당 최대 2명 |
| 3. 아이덴티티 | 구단 컬러 유니폼, 등번호 | 벡터 합성 레이어(L2). 같은 구단 내 등번호 중복 금지 |

**헤어 길이 카테고리**: ①숏(턱선 위) ②보브(턱~어깨) ③미디엄(어깨~가슴) ④롱(가슴 아래) ⑤묶음(포니테일/트윈테일/당고/땋기 — 경기용 묶음 헤어를 적극 권장, 42명 중 40% 이상).

**눈 형태 3종**: 기본(둥근), 츠리메(눈꼬리 올라감·강한 인상), 타레메(눈꼬리 내려감·부드러운 인상). 구단당 세 종류가 모두 등장하도록 배분.

### 1.4 복장·연출 규정

> **v0.2 변경**: 목표 등급을 **12세 이용가 → 15세 이용가**로 올렸다.
> 12세 판의 금지선(넥라인 쇄골 아래 3cm, 인심 4~5인치, 배꼽 노출 금지, 엉덩이·가슴 중심 프레이밍 금지,
> 땀은 얼굴·목·팔만)이 **경기 장면의 박진감까지 같이 잘라 냈다**는 것이 히어로 시험에서 드러났다.
> 되돌릴 경우를 대비해 옛 값은 1.4.4 에 남겨 둔다.

#### 1.4.1 살려야 하는 것 — 여자배구의 매력 (금지선이 아니라 **요구 사항**이다)

1.4.2 는 "하지 마라"의 목록이지만, 이 절은 **"이게 없으면 QA 탈락"** 이다. 규정을 지키느라 밋밋해지는 것이
이 프로젝트에서 실제로 일어난 실패다.

| 항목 | 요구 |
|---|---|
| **높이** | 점프의 정점. 발이 바닥에서 확실히 떠 있고, 로우앵글로 올려다봐 키와 도약이 과장되게 읽힐 것 |
| **힘** | 팔·어깨·허벅지의 근육 라인이 보일 것. "운동하는 몸"이지 마른 몸이 아니다 |
| **긴장** | 얼굴에 승부의 순간이 있을 것 — 이 악물기, 노려보기, 숨. 무표정 금지 |
| **속도** | 머리카락·옷자락·땀방울이 동작 방향으로 흐를 것. 정지 포즈 금지 |
| **몸의 곡선** | 스파이크의 활처럼 휜 상체, 디그의 낮은 자세 — **동작에서 나오는 실루엣은 살릴 것.** 밋밋하게 펴지 말 것 |
| **유니폼** | 실제 배구복대로 몸에 맞는 핏. 헐렁한 티셔츠처럼 그리지 말 것 |
| **땀** | 얼굴·목·어깨·팔·허벅지에 허용. 격렬함의 표현이다 |
| **조명** | 등급별 연출(3.5) 을 아끼지 말 것. 림라이트·스포트라이트·플레어가 카드값을 만든다 |

#### 1.4.2 금지선

| 항목 | 규정 |
|---|---|
| **나체·속옷** | 금지. 유니폼 착용 상태 유지 |
| **성행위·성적 자세** | 금지. 포즈는 배구 동작에서 나온 것만 |
| **과도한 노출** | 금지. 크롭탑·초단 스판·깊은 가슴골 컷은 쓰지 않는다. 배꼽이 잠깐 보이는 정도는 무방 |
| **투시·국부 묘사** | 금지. 젖은 천은 실루엣까지, 유두·국부 묘사 금지 |
| **업스커트류** | 금지 — 시선이 쇼츠 안쪽을 향하는 구도 |
| **부위 클로즈업** | 금지 — 얼굴 외의 신체 부위만 크게 잡는 컷 |
| **아동형 체형** | 금지. 전원 성인(18세 이상) 설정이며 그렇게 보여야 한다 |
| **실존 브랜드** | 배구공·신발·유니폼에 실제 상표 색 배열·마크 금지. 공식구는 흰 `#F4F5F8` + 민트 `#3EC1B3` + 코랄 `#FF6B57`(4.8). **상표 문제라 등급과 무관하다** |
| **화면 내 문자** | 금지 — 로고·번호·워터마크·제목. 번호는 벡터 후합성(5.3) |
| **필수 장비** | 무릎 보호대(양쪽)·양말·배구화 |

#### 1.4.3 왜 19세가 아닌가

한 번은 청소년이용불가까지 열기로 했다가 되돌렸다. 실제로 원한 것이 **"경기의 박진감과 선수의 매력"** 이었고
그건 15세 안에서 전부 된다. 19세는 원하지 않는 것(나체·성행위)을 허용하는 대신 대가만 남는다.

- 국내 게임물관리위원회 청소년이용불가 등급, 성인 인증 필수
- 구글플레이·앱스토어 노출·검색 제한, 국내 구글플레이는 청불 유통 자체가 제약
- 주요 광고 네트워크 다수가 집행 거부 — **유통·마케팅 경로가 게임보다 먼저 막힌다**

15세는 국내·일본 가챠 게임 다수가 있는 구간이라 심의·광고 리스크가 낮다.

#### 1.4.4 12세 판 금지선 (되돌릴 때 복원용)

넥라인 = 쇄골선 아래 3cm 이내, 가슴골 묘사 금지 · 밑단 = 배꼽 노출 없음(tuck-in 고정) ·
하의 인심 = 사타구니→무릎의 1/3 이상 아래, 밀착 부위 형태 강조 금지 ·
카메라 = 엉덩이·가슴 중심 프레이밍 금지 · 땀 = 얼굴·목·팔에 소량만 · 체형 = 가슴·허리 과장 금지.

**등급 확정 시점**: 히어로 3명 단계. 42명을 만든 뒤 되돌리면 전량 재제작이다.

프롬프트 네거티브(6절)와 QA 체크(8절)는 1.4.2 를 검사하고, 1.4.1 은 **채택 판정 기준**으로 쓴다.

### 1.5 오리지널 원칙

1. **실존 인물 모사 금지**: 실제 선수·연예인의 얼굴·헤어·등번호 조합을 참고하지 않는다. 포즈 레퍼런스로 실제 경기 사진을 볼 때는 **관절 위치만** 참고하고 구도·의상·인물을 옮기지 않는다.
2. **특정 작품 모사 금지**: 특정 배구 만화/애니(예: 하이큐)의 캐릭터·유니폼·구도를 연상시키는 디자인 금지. 셀프 체크: "이 카드를 보고 특정 작품 이름이 3초 안에 떠오르면 탈락".
3. **작가 화풍 모사 금지**: 프롬프트에 작가명·작품명·스튜디오명 **일절 금지**. LoRA도 특정 작가 스타일 LoRA 사용 금지(캐릭터 LoRA는 자기 데이터로만 학습).
4. **상표 금지**: 실제 배구공 브랜드 색 배열, 스포츠 브랜드 로고·줄무늬, 실제 리그 로고 금지. 공은 4.8절의 "게임 공식구" 디자인만 사용.
5. **유사도 셀프 체크**: 신규 캐릭터 승인(7.4절) 시 "기존 유명 캐릭터와 헤어+눈색+유니폼색 3요소가 동시에 겹치는가"를 확인 항목에 포함.

## 2. 스타일 규격표

### 2.1 기준 단위 H

모든 비율은 **H = 머리 높이(정수리~턱 끝, 헤어 볼륨 제외)**로 표기한다. 해상도별 예시:

| 에셋 | 캔버스 | 화면 내 H(권장) | 비고 |
|---|---|---|---|
| 카드 풀 일러스트 | 2048×2732 | 480~620px | 포즈에 따라 상반신 클로즈업이면 커짐 |
| 스탠딩 | 1440×2560 | 300~340px | 7~7.5등신 전신 기준 |
| 썸네일 | 512×512 | 약 230px | 카드에서 크롭 |
| SD 토큰 | 256×256 | 약 110px (2등신) | 별도 규격(4.5절) |

### 2.2 선 (라인아트)

| 항목 | 굵기 (H 대비) | 카드(H=500) | 스탠딩(H=320) | 색 |
|---|---|---|---|---|
| 외곽 실루엣 선 | 1.2% H | 6px | 4px | 인접 색의 어두운 톤(컬러 트레이스). 순수 검정 금지 |
| 내부 주요 선(옷 경계, 팔·다리 분리) | 0.7% H | 3.5px | 2.5px | 동일 규칙 |
| 디테일 선(머리카락 결, 주름) | 0.4% H | 2px | 1.5px | 동일 규칙, 끝이 가늘어지는 테이퍼 |
| 눈꺼풀 상단 라인 | 2.0% H(가장 굵음) | 10px | 6.5px | 다크 브라운/헤어 색 계열(2.5절) |

컬러 트레이스 규칙: 선 색 = 해당 영역 그림자색을 명도 −25%, 채도 +10% 한 값. 피부 외곽 `#5A3A32` 계열, 머리카락 외곽 = 헤어 그림자색 −25%, 흰 유니폼 외곽 `#6B6F85`.
선 끝은 테이퍼(강약) 필수 — 균일 굵기 벡터 느낌 금지. 원거리(작은) 부위일수록 선 굵기 비율 유지(픽셀 고정 금지).

### 2.3 채색

| 항목 | 규격 |
|---|---|
| 기본 방식 | **셀 셰이딩 2단**(베이스 + 1차 그림자). 경계는 딱딱한 에지 |
| 3단(2차 그림자) | 폐색 부위 한정: 턱 밑, 목, 겨드랑이, 팔꿈치 안쪽, 앞머리 밑 그림자, 옷 안쪽. 전체 면적의 **15% 이하** |

- 주의: 손가락 10개가 전부 노출 → 리터치 비용 최상. R 등급은 한 손을 공에 부분 가림 허용.

**② OH — 스파이크(레프트 강타)**

- 카메라: 로우앵글 15~20°, 3/4 정면 우측(공격 팔 쪽이 카메라에 가까움). 허벅지 중간~손끝까지.
- 몸: 공중. 상체를 활처럼 비틀어(bow-and-arrow) 오른쪽 어깨가 뒤로 당겨졌다가 앞으로 나온 순간. 골반은 카메라 정면, 어깨는 30° 회전.
- 팔: 타격 팔(오른팔) 머리 위 최대 신전, 손바닥 열림(손가락 모아 약간 벌림), 손목 스냅으로 손바닥이 아래·앞을 향함. 반대 팔은 팔꿈치를 굽혀 가슴 앞으로 당김.
- 다리: 양 무릎 뒤로 접힘(발뒤꿈치가 엉덩이 쪽), 발끝 아래로.
- 공: 손바닥 접촉 직후, 손보다 0.3 지름 앞·아래. 카드 (0.62W, 0.10H).
- 시선: 공/상대 코트 방향, 집중한 눈(눈썹 직선화). 머리카락은 위로 흩날림.

**③ OP — 후위 공격(백어택, 파이프/D)**

- 카메라: 아이레벨, 3/4 측면(좌측 45°), OH보다 넓은 프레이밍으로 **바닥의 어택 라인(3m 선)이 도약 지점 뒤에 보이게** 한다 — "후위"임을 그림으로 읽히게 하는 핵심.
- 몸: 멀리뛰기형 수평 도약(앞으로 뻗은 실루엣). 몸이 OH보다 길고 직선적. 등 곡선은 작고 몸 전체가 사선(30°).
- 팔: 타격 팔 최대 신전이며 앞쪽으로 약간 기울어짐, 반대 팔은 앞으로 뻗어 균형.
- 다리: 앞다리 무릎 굽혀 앞으로, 뒷다리 뒤로 길게.
- 공: 손 앞 0.2 지름, 카드 (0.60W, 0.14H). 
- 시선: 상대 블로커 너머(카메라 우측 원경). 파워를 강조하는 이펙트(SR+): 공 뒤 짧은 궤적선.

**④ MB — 블로킹**

- 카메라: 상대 코트 쪽에서 네트 높이보다 약간 아래(로우앵글 10°), 정면. 
- 몸: 수직 점프, 몸통 곧게(젖힘 없음), 배는 네트를 향하고 무릎은 살짝 접힘.
- 팔: 양팔을 곧게 위로 뻗어 네트 위로 넘김(팔꿈치 완전 신전). 손은 활짝 펼치고 손바닥이 카메라를 향함, 양 엄지 간격 = 공 지름의 0.5 이하(공이 빠지지 않게).
- 네트: 흰 상단 밴드(폭 7cm)가 가슴~어깨 높이를 가로지름. 네트 그물은 얇은 선 격자, 캐릭터 앞에 걸치지 않도록(뒤에 있음).
- 공: 양손 바로 앞(카메라 쪽) 접촉 순간, 손에 20% 가려짐. 카드 (0.5W, 0.16H).
- 시선: 정면 아래(공격수 쪽)로 내려다봄, 강한 눈.
- 주의: 장신 강조를 위해 카드 상단 여백을 작게(손끝이 세이프 영역 상단선에 닿게).

**⑤ L — 디그(수비)**

- 카메라: 바닥에 가까운 로우앵글, 3/4 정면. 넓은 프레이밍(전신).
- 몸: 낮은 자세. 한쪽 다리(오른) 옆으로 길게 뻗고 반대 무릎은 깊게 굽혀 바닥 근접. 상체 앞으로 숙임.
- 팔: 양팔을 붙여 플랫폼(전완 안쪽 면). 손은 한 손이 다른 손을 감싸 쥐고 양 엄지가 나란히 위. 플랫폼은 카메라 쪽으로 30° 기울어짐.
- 공: 전완 플랫폼 중앙에 접촉 순간(접촉면에 약간 눌린 표현 금지 — 배구공은 단단함). 카드 (0.45W, 0.45H). 
- 시선: 공. 머리카락과 땀방울로 속도감.
- 유니폼: **리베로는 구단 대비색**(5.4절). 이 카드만 봐도 리베로임을 알 수 있어야 함.
- SSR 변형: 다이빙(플라잉 디그) — 몸이 바닥과 평행, 한 손 팬케이크.

### 3.3 서브 포즈(대체/각성용)

GDD 9.3의 대표 동작 목록에 있는 서브는 OH/OP의 각성 일러스트 또는 픽업 대체 포즈로 사용한다. 점프 서브 토스 직후: 카메라 후방 3/4, 공은 머리 위 1.5지름, 타격 팔 뒤로 당김, 시선 공. 리베로는 서브 포즈 금지(GDD 룰: 리베로 서브 불가).

### 3.4 포즈 레퍼런스·ControlNet 확보 방법

포즈 뱅크는 **포지션 5종 × 변형 3개 = 15개**를 먼저 만들고 42명이 공유한다(같은 포지션 카드가 완전히 같은 실루엣이 되지 않도록 변형을 순환 사용).

| 방법 | 비용 | 절차 | 비고 |
|---|---|---|---|
| A. 셀프 촬영 | 무료 | 스마트폰 삼각대 + 타이머, 3.2절 묘사대로 본인이 포즈 → OpenPose 전처리기로 스켈레톤 추출 → OpenPose 에디터에서 관절 보정 | 점프 포즈는 의자·침대 위에서 "공중 자세"만 재현하면 됨. 안전 우선. 가장 원본성 확실 |
| B. 3D 포즈 툴 | 무료~저가 | PoseMy.Art(웹), Magic Poser, Easy Pose, DesignDoll, Blender(Rigify 기본 릭) 등에서 포즈 → 카메라 앵글 설정 → OpenPose/Depth 렌더 출력 | 로우앵글 투시가 정확. Blender면 Depth·Normal 맵도 함께 출력해 ControlNet 다중 사용 |
| C. 생성→추출 반복 | 무료 | 프롬프트만으로 생성한 러프에서 OpenPose 추출 → 에디터에서 수정 → 재생성 | 속도 빠르나 손 자세는 반드시 수동 보정 |
| D. 실제 경기 사진 | 무료 | **관절 위치 참고만**. 스켈레톤을 직접 추출하되 구도·인물·의상은 옮기지 않음(1.5절) | 특정 사진 1장의 구도를 그대로 재현하는 것은 금지 |

ControlNet 운용 규칙(초기 권장값):
- 주: **OpenPose(손 포함)** 가중치 0.8, 종료 스텝 0.7 → 포즈는 강제하되 마지막 30%는 자유(선·명암 자연스러움).
- 보조(옵션): Depth 가중치 0.4(투시 강조 카드), 공 위치 고정용 Scribble/Canny에 공 원형만 그려 넣기 0.5.
- 산출물: `art/05_shared/pose/{POS}_{action}_{nn}.json`(OpenPose JSON) + `.png`(생성 해상도 스켈레톤) + `_ref.jpg`(원천 레퍼런스: 본인 촬영본/3D 렌더).
- 손 형태(세터의 다이아몬드, 블로킹의 펼친 손, 디그의 맞잡은 손)는 OpenPose 손 키포인트만으로는 부족하므로 **손 부분은 Depth 또는 리터치로 확정**한다.

### 3.5 등급별 포즈·연출 강도

| 등급 | 포즈 | 카메라 | 이펙트/광원 | 배경(엔진) |
|---|---|---|---|---|
| N(제네릭) | 상반신 정지(공 들고 서 있음) | 아이레벨 정면 3/4 | 없음 | 단색 |
| R | 3.2절 표준 포즈 | 표준 앵글 | 림 없음, 땀 1~2방울 | 그라데이션 |
| SR | 표준 포즈 + 머리카락·옷자락 동세 | 앵글 ±10° 과감 | 얇은 림라이트, 공 궤적선 짧게, 스피드라인 소량 | 패턴 + 광택 |
| SSR | 포즈 변형(점프 토스·플라잉 디그 등) | 강한 로우앵글·투시(포어쇼트닝) | 굵은 림 + 번짐, 스포트 하이라이트, 빛 줄기, 파티클은 엔진 | 애니메이션 |
| SSR 각성 | 유니폼 변화 + 연출 포즈(4.6절) | 자유 | SSR + 스포트 직사(2.6절) | 애니메이션 + 프레임 진화 |

"화려함 편차" 판정: 등급이 낮은 카드가 상위 등급보다 이펙트·림·앵글이 강하면 QA 탈락(8.2절).

### 4.3 썸네일 크롭 규칙 (512×512)

1. `p001_meta.json`의 `face.cx, face.cy, face.h`(카드 좌표계, 리터치 완료 후 수동 입력 또는 얼굴 검출)를 읽는다.
2. 크롭 정사각 한 변 = **2.2 × face.h**, 중심 = (cx, cy + 0.15·face.h) (눈보다 약간 아래 = 얼굴 전체 + 목 일부).
3. 세이프 영역을 벗어나면 안쪽으로 밀어 넣는다(얼굴이 잘리지 않게 우선).
4. 512×512로 Lanczos 다운스케일, 알파 유지. 배경은 엔진(등급색)이 깔린다.
5. 스크립트 1개(Python + Pillow)로 `art/04_export/**/p*_card.png` → `p*_thumb.png` 일괄 생성. 각성은 `_awk` 동일 처리.

### 4.4 스탠딩 (1440×2560) + 표정 파츠

**본체 규격**

| 항목 | 규격 |
|---|---|
| 캔버스 | 1440×2560, 9:16 |
| 스케일 | **12px/cm** 고정. 발바닥 기준선 y=2440(하단 여백 120px). 195cm → 머리 위 y=100 |
| 포즈 | 아이레벨, 몸 3/4(좌측 15° 회전), 얼굴 정면 가까이. 한 손 허리 또는 양팔 자연스럽게. 공 없음(옵션: 옆구리에 낀 공은 SSR만) |
| 복장 | 홈 유니폼(5절). 리베로는 리베로 색 |
| 광원 | 2.6절 동일. 림라이트는 등급 무관 **없음**(대화 화면 배경이 다양하므로) |
| 레이어 순서(아래→위) | `stand_body`(몸+얼굴 기본표정) → `face_{expr}` → `stand_hairf`(앞머리) |

**표정 파츠 규격**

| 항목 | 규격 |
|---|---|
| rect | 캐릭터별 고정 512×512 정사각. 위치는 눈썹 상단 −0.08H ~ 턱 아래 +0.05H를 포함하도록 잡고 `meta.face_rect = {x, y, w:512, h:512}`로 기록 |
| 내용 | 눈썹·눈·코·입·홍조·땀·눈물 + 그 아래 피부(불투명). rect 밖(또는 얼굴 타원 밖)은 투명. 타원 경계는 피부색으로 2px 페더 |
| 앞머리 | 앞머리가 눈썹을 조금이라도 덮는 헤어스타일은 `stand_hairf` 분리 필수 → 표정 파츠가 앞머리를 가리지 않게. 앞머리 밑 이마 피부는 본체에 그려 둔다 |
| 4종 정의 | neutral(기본: 입 다물고 옅은 미소, 시선 카메라) / joy(기쁨: 크게 웃음, 입 열림, 홍조, 하이라이트 3개 허용, 눈 감은 웃음 변형 가능) / tired(피로: 반쯤 감긴 눈, 땀 2~3방울, 입 살짝 벌림, 눈썹 처짐) / down(좌절: 시선 아래, 눈썹 안쪽 올림, 입 다물고 이 악문 선, 눈가 맺힌 눈물 1개까지. **흐르는 눈물 금지**) |
| 금지 | 표정 간 눈 위치·눈 크기·얼굴 윤곽 변화. 바뀌는 것은 눈꺼풀 형태·눈썹·입·홍조·땀뿐 |

**제작 절차(인페인트 방식)**: 본체 승인 → 얼굴 rect를 마스크로 인페인트(동일 시드·동일 프롬프트 + 표정 태그, denoise 0.45~0.6) 4회 → 리터치 → rect로 잘라 저장. 4.10절 Unity 쪽에서는 face_rect 좌표로 자식 Image를 배치한다.

## 5. 유니폼 디자인 규칙

### 5.1 구단 컬러 적용 비율

각 구단은 `primary`, `secondary`, `neutral`(흰/검/네이비 중 하나) 3색을 가진다(값은 `world.md`에서 확정, 아래는 규칙).

| 부위 | 홈 | 원정 | 리베로(홈/원정 공통) |
|---|---|---|---|
| 상의 몸통(70%) | primary | 흰 `#F4F5F8` | **secondary**(primary와 대비되어야 함; 대비 부족 시 구단별 지정 `libero` 색) |
| 사이드 패널·칼라·소매 끝(20%) | secondary | primary | primary |
| 파이핑·번호·로고(10%) | neutral 또는 흰 | primary/secondary | neutral 또는 흰 |
| 쇼츠 | neutral(네이비/블랙). primary가 이미 어두우면 primary | 홈과 동일 | 홈과 동일 |
| 양말 | 흰 | 흰 | 흰 |
| 무릎 보호대 | 흰 또는 검 중 구단별 고정 | 동일 | 동일 |
| 배구화 | 흰 베이스 + primary 포인트 | 동일 | 동일 |

구단 간 primary 색상(H)은 서로 **40° 이상** 떨어지게 하고, 흰색·검정을 primary로 쓰는 구단은 최대 1개. 리베로 색이 다른 구단의 primary와 같아지는 경우 허용(경기 화면에서는 팀 외곽선 색으로 구분).

### 5.2 AI 생성 시 "빈 영역" 확보 지침

로고·번호·엠블럼은 AI가 그리지 않는다. 생성 단계에서 아래를 강제한다.

- Positive: `plain jersey, solid color jersey, no logo, no text, no print, blank jersey`
- Negative: `text, logo, letters, numbers, sponsor, emblem, watermark, stripes on chest, pattern`
- 그래도 생기는 자국은 리터치에서 **가슴 중앙·등 상부·좌측 소매를 플랫 색으로 덮고 주름 그림자만 남긴다**(옷 주름은 살리고 무늬만 지움).
- 빈 영역 크기(5.3절 템플릿과 동일): 가슴 로고/번호 존 = 어깨 폭의 30% × 20%, 등 번호 존 = 어깨 폭의 50% × 40%, 소매 엠블럼 존 = 소매 폭의 60% 원형.

### 5.3 벡터 후합성 절차 (L2 레이어)

1. `uni_{team}_{kit}.svg` 템플릿에서 번호(폰트)·엠블럼·리그 마크를 PNG로 내보낸다(2048 캔버스 기준 300~400px 높이).
2. 일러스트 위에 배치 → **자유 변형/워프(퍼펫 워프·메시 변형)로 몸통 곡면과 원근에 맞춤**(원근이 강한 로우앵글 카드에서 평평하게 붙어 있으면 실패).
3. 일러스트의 유니폼 그림자 레이어를 복제해 번호 위에 **곱하기(Multiply)** 로 얹어 천 위에 인쇄된 느낌을 만든다. 주름이 번호를 가로지르는 곳은 그림자 경계에 맞춰 번호 픽셀을 2~3px 지운다.
4. 외곽선: 번호 가장자리에 컬러 트레이스 선 0.4% H(2.2절 디테일 선 굵기).
5. 합성 결과는 `card.png`에 병합해 납품한다(엔진 런타임 합성 아님 — 원근 워프가 필요하므로). 단 **스탠딩과 토큰은 정면·평면이므로 엔진 합성 가능** → 스탠딩은 번호를 그리지 않고 `meta.number_rect`로 위치를 기록, 코스튬 교체 확장을 대비.

### 5.4 홈/원정·리베로 규칙

- 카드·스탠딩 기본 = **홈 유니폼**. 원정은 코스튬(추후 라이브옵스).
- 리베로 카드·스탠딩·토큰은 항상 리베로 색(실제 배구 규칙과 동일, 팀원과 다른 색). 리베로가 홈 유니폼을 입은 그림은 QA 탈락.
- 한 카드에 여러 인물 금지(라이선스·비용 단순화). 각성도 단독.

### 5.5 각성용 "결승전 사양" 유니폼

primary/secondary 비율 반전(몸통 secondary 70% + primary 패널) 또는 primary 유지 + 메탈릭 골드 파이핑(등급색과 통일). 번호·엠블럼 위치는 동일 템플릿. 형태(소매 길이·넥라인·쇼츠 길이)는 1.4절 규정 그대로 — 각성이라고 노출이 늘지 않는다.

## 7. 캐릭터 일관성 프로토콜

### 7.1 등급별 방식

| 등급 | 방식 | 근거 |
|---|---|---|
| SSR(10) + 히어로 | **캐릭터별 LoRA** + 프롬프트 블록 + 시드 기록. LoRA 학습이 불가능한 환경이면 IP-Adapter 계열 레퍼런스 조건부 생성(얼굴 레퍼런스 3장) | 카드·각성·스탠딩·표정 4종 등 노출 빈도가 높고 각도가 다양 |
| SR(14) | 프롬프트 블록 + 시드 고정 + IP-Adapter(레퍼런스 1~3장) 권장 | 카드+스탠딩 2종이라 LoRA 비용 대비 효과 낮음. 불일치가 반복되면 LoRA로 승격 |
| R(18) | 프롬프트 블록 + 시드 고정 | 리터치에서 눈·헤어 색을 팔레트 값으로 맞추면 충분 |

**캐릭터 프롬프트 블록**: 6.2절 슬롯 중 `{skinTone}~{eyeShape}`까지의 외모 태그 묶음. 설정 시트에 한 줄로 고정하고 모든 생성에 그대로 복사.

### 7.2 LoRA 학습 데이터셋 구성

| 항목 | 규격 |
|---|---|
| 장수 | **24~40장**(레퍼런스 시트에서 승인한 얼굴을 시드로 생성·리터치한 이미지. 외부 이미지 사용 금지) |
| 앵글 | 정면 20% / 3/4 좌·우 40% / 측면 15% / 뒷모습·부감·앙시 25% |
| 프레이밍 | 얼굴 클로즈업 35% / 상반신 35% / 전신 30% |
| 표정 | neutral 50% + joy/tired/down/집중 각 10~15% |
| 복장 | 홈 유니폼 50% / 각성 유니폼 20% / 트레이닝복·사복 30% (유니폼이 얼굴 특징과 함께 굳는 것을 방지) |
| 배경 | 단색 40% / 코트 40% / 기타 20% |
| 해상도 | 1024 기준 버킷(SDXL). 리터치로 손·눈 오류를 고친 것만 투입(오류를 학습시키지 않는다) |
| 캡션 규칙 | `p001char, 1girl, <가변 요소만>` — **고정 특징(헤어 색·형태, 눈 색)은 캡션에서 제외**(LoRA가 흡수), 가변 요소(옷·포즈·표정·배경·앵글)는 모두 기술 |

| 판정 | 학습 후 시드 3개 × 앵글 3개 = 9장 생성 → 7.4절 비교 보드에서 얼굴 동일성 판정. 과적합(옷·배경까지 고정되면) → 스텝 −30% 재학습 |
| 버전 | `p001_v1.safetensors` → 각성 유니폼 추가 학습 시 `v2`. 사용 버전을 meta에 기록 |

### 7.3 레퍼런스 조건부 생성(LoRA 대체/보조)

- IP-Adapter(얼굴 특화 변형 포함) 가중치 0.5~0.7, 레퍼런스는 승인된 정면·3/4 얼굴 2~3장. 스타일이 사진풍으로 끌리면 가중치 −0.1.
- Reference-only 계열 ControlNet은 헤어 형태 유지에 유리, 얼굴 동일성은 약함 → IP-Adapter와 병용.
- 사용한 모델(어댑터) 파일도 라이선스·해시 기록 대상.

### 7.4 신규 캐릭터 승인 절차 ("기존 카드 3장 비교")

1. `art/00_guide/compare_board.kra` 템플릿(4열 × 2행, 각 셀 1024×1366) 열기.
2. 1행: 신규 카드 + 기존 승인 카드 3장 — **같은 등급 1장, 같은 구단 1장, 같은 포지션 1장**(겹치면 다른 캐릭터로 대체). 동일 스케일(카드 원본 50%).
3. 2행: 4장의 얼굴을 각 H=400px로 맞춰 확대 크롭 + 2.5절 그리드 오버레이.
4. 판정표(각 1~5점, **모두 4점 이상이면 승인**, 3점 이하 항목이 하나라도 있으면 수정 후 재심):

| 항목 | 4점 기준 |
|---|---|
| 선 굵기·테이퍼 | 외곽/내부 굵기 비율이 기존과 ±20% 이내 |
| 그림자 단수·경계 | 2단 셀 + 국소 3단, 경계 하드니스 동일 |
| 그림자 색 규칙 | 색상 +15° 청/보라, 채도·명도 변화가 규칙 범위 |
| 눈 규격 | 눈 높이 0.20H ±10%, 하이라이트 2개 위치 동일, 상안검 굵기 동일 |
| 얼굴 비율 | 눈 중심 0.55H, 입 0.84H 등 그리드 일치 |
| 채도 레벨 | 피부·헤어 평균 채도가 팔레트 값 ±8%p (툴 히스토그램/스포이드) |
| 체형·등신 | 포지션 규격(3.1절) 안 |
| 등급 연출 강도 | 3.5절 표에 맞고, 같은 등급 카드와 화려함이 비슷 |
| 구분성 | 같은 구단 카드와 헤어 길이·색이 겹치지 않음(1.3절) |
| 오리지널 | 유명 캐릭터와 헤어+눈색+유니폼색 3요소 동시 일치 없음 |

5. 승인 보드 PNG를 `01_refs/{pid}/approval_{date}.png`로 저장. 재심은 최대 2회, 그래도 실패하면 레퍼런스 시트로 되돌아간다.
