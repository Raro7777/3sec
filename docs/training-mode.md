# 육성 모드 상세 설계 — 신인 → 졸업 (training-mode v0.1)

> 상태: 초안 v0.1. GDD v0.2의 1절(코어 루프)·2절(스탯/포지션/희귀도)·3절(육성 모드)·7절(경제)을 구체화한다.
> 이 문서의 모든 상수는 **초기값**이며 튜닝 전제다. 본문 수치는 규칙을 그대로 구현한 간이 시뮬레이터(파이썬, 몬테카를로 n=5,000)로 상호 모순이 없음을 확인한 값이다(12절 참고).
> 범위 밖: 평가전 내부 판정(랠리 시뮬 코어, `match-sim.md` 담당), 재화 세부 수치(경제 문서), 카드별 스토리 텍스트(시나리오).

## 1. 설계 목표와 리듬

### 1.1 목표

1. **한 세션에 1회 완주.** 육성 1회 ≤ 10분(수동), 스킵/자동 3~4분. 우마무스메(1회 40~60분)와 달리 "짧게 여러 번"이 리텐션 축이다.
2. **턴당 의사결정은 20~30초.** 화면에 "예상 상승치"와 "부상 확률"을 숫자로 노출해 계산이 아니라 **비교**만 하게 만든다.
3. **읽을 게 없어야 한다.** 이벤트 본문 1~2줄, 선택지 2개. 서사는 졸업 후 카드 스토리(별도)로 밀어낸다.
4. **결과의 분산.** 같은 카드를 다시 키워도 스탯 분포·해금 스킬·등급이 달라져 "한 번 더"가 성립해야 한다. 단, 실력 차이가 운을 이겨야 한다(최적 vs 랜덤 OVR 차 ≥ 4).

### 1.2 시간 예산 (12턴 기준)

| 구간 | 수동 플레이(목표) | 스킵 | 자동 진행(AI 코치) |
|---|---|---|---|
| 편성(카드 + 코치/서포트 선택) | 30s | 10s | 10s(프리셋) |
| 캠프 인트로 1컷 | 5s | 0 | 0 |
| 턴 루프 12턴 × (결정 25s + 결과 연출 4s) | 348s | 12 × 4s = 48s | 12 × 10s = 120s |
| 이벤트 평균 8회 × 7s (≤13회) | 56s | 8 × 2s = 16s | 8 × 4s = 32s |
| 평가전 3회 × 25s (요약 카드) | 75s | 3 × 8s = 24s | 3 × 8s = 24s |
| 졸업(스탯 리빌 · 등급 · 인스턴스 비교) | 40s | 15s | 30s |
| **합계** | **≈ 554s ≈ 9.2분** | **≈ 113s ≈ 1.9분** | **≈ 216s ≈ 3.6분** |

턴당 결정이 상한 30초까지 늘어나면 합계 10.2분 → 10분 제약이 **평균 결정 시간 ≤ 27초**를 강제한다. 프로토타입에서 턴 결정 시간을 로깅해 이 값을 검증한다(12절 H7).

### 1.3 왜 12턴인가

- 시간: 12 × 29s = 5.8분이 턴 루프 예산. 14턴이면 6.8분 + 고정 오버헤드 3.4분 = 10.2분으로 상한 초과. 10턴이면 여유는 있으나 아래 리듬이 깨진다.
- 리듬: 피로 수식(훈련 +15 순증, 휴식 −45)상 **"훈련 3 + 휴식 1" = 4턴이 한 블록**이다. 12턴 = 3블록. 각 블록 끝(T4/T8/T12)에 평가전을 두면 "훈련 → 점검 → 훈련"이 세 번 반복되어 성장이 체감된다.
- 결정 밀도: 12번의 선택 중 ~9번이 훈련 선택, ~3번이 휴식/특훈 타이밍. 체감 수확 곡선(4.3절)상 한 스탯을 상한 근처까지 올리는 데 5~6턴이 들어 "핵심 2개 완성 + 1개 절반"이 12턴의 자연스러운 결과가 된다. 즉 **모든 것을 다 올릴 수 없어 선택이 생긴다.**

### 1.4 텍스트량 상한

| 요소 | 상한 | 비고 |
|---|---|---|
| 훈련 결과 | 숫자 배지 + 플레이버 1줄 ≤ 20자 | 플레이버는 훈련별 10개 풀에서 랜덤 |
| 랜덤 이벤트 본문 | 2줄 ≤ 60자 | 선택지 2개, 각 ≤ 12자 |
| 선택 결과 | 1줄 ≤ 40자 + 효과 배지 | |
| 스토리 이벤트(카드별) | 최대 3컷, 컷당 2줄 ≤ 60자 | 스탠딩 표정 차분 4종 활용 |
| 평가전 요약 | 스코어 + 개인 기록 3~4개 + 코멘트 1줄 | 관전은 옵션 |
| 졸업 코멘트 | 2줄 | 등급별 템플릿 |

## 3. 턴당 선택지

### 3.1 훈련 5종

주 스탯 ×1.0, 부 스탯 1 ×0.5, 부 스탯 2 ×0.25. 부 스탯 배정은 "한 훈련이 신체 스탯 하나 + 정신/기술 스탯 하나를 곁들인다"는 원칙으로, 10종 스탯이 모두 훈련으로 닿게 했다(파워 3회, 스태미나 2회, 스피드 2회, 멘탈 2회, 디그 1회).

| 훈련 | 주 스탯(×1.0) | 부 스탯 1(×0.5) | 부 스탯 2(×0.25) | 피로 | 부상 위험 계수 | 컨셉 |
|---|---|---|---|---|---|---|
| 서브 | serve | power | mental | +20 | 0.8 | 반복 서브 + 배짱 |
| 리시브 | receive | dig | stamina | +20 | 1.0 | 수비 랠리, 오래 뛴다 |
| 토스 | set | mental | speed | +20 | 0.7 | 판단력 + 잔발 |
| 스파이크 | spike | power | stamina | +20 | 1.3 | 점프 반복, 무릎 부담 |
| 블로킹 | block | speed | power | +20 | 1.2 | 반응 + 점프 |

디그가 리시브 훈련의 부 스탯으로만 오르는 점은 의도다. 리베로·OH는 리시브 훈련이 주력이라 디그가 자연히 따라오고, 그 외 포지션은 디그가 낮아도 OVR 가중치가 작다(8.2절).

### 3.2 포지션 적성

카드 데이터 `aptitude[훈련]`. 기본값은 포지션 표, 카드별로 덮어쓸 수 있다(예: "리시브 되는 OP" 같은 개성).

| 포지션 | 서브 | 리시브 | 토스 | 스파이크 | 블로킹 |
|---|---|---|---|---|---|
| S | B | B | **S** | C | B |
| OH | A | A | C | A | B |
| OP | A | C | D | **S** | B |
| MB | B | C | D | A | **S** |
| L | D | **S** | B | D | D |

적성 배수: **S 1.30 / A 1.15 / B 1.00 / C 0.70 / D 0.40**.

L의 스파이크 훈련 = 적성 D(0.40) × 잠재력 잔여 ~6(L 스파이크 potential은 초기 +6 이내로 설정) → 첫 턴 +1.5, 이후 0.5 이하. "거의 무의미"가 수식으로 나온다. 적성표는 UI에서 훈련 버튼 위 등급 아이콘으로 상시 노출한다.

### 3.3 휴식

| 효과 | 값 |
|---|---|
| 피로 | −45 (하한 0) |
| 컨디션 | +1단계 (확률 70%) |
| 멘탈 | +1 고정 |
| 부상 위험 | 0 |
| 부수 효과 | 다음 턴 특훈 등장 조건(피로 ≤ 40) 충족에 기여 |

### 3.4 특훈 (조건부 등장)

턴 시작 시 아래 조건 중 하나면 6번째 버튼으로 등장. 등장 시 그 턴에만 유효.

| 등장 조건 | 확률 |
|---|---|
| 피로 ≤ 40 **그리고** 컨디션 호조 이상 | 25% / 턴 |
| 직전 평가전 MVP(활약도 ≥ 80) | 다음 턴 100% |
| 코치/서포트 효과(9절 채택 시) | +10~20%p |

| 특훈 종류 | 대상 스탯(가중) | 기본치 배수 | 피로 | 부상 위험 계수 | 힌트 |
|---|---|---|---|---|---|
| 포지션 특훈 | 핵심 3스탯 ×1.0 / ×0.7 / ×0.5 (8.2절 CORE3) | ×1.5 | +30 | 1.5 | +1 |
| 체력 특훈 | stamina ×1.0 / speed ×0.7 / power ×0.5 | ×1.5 | +30 | 1.5 | +1 |
| 멘탈 캠프 | mental ×1.0 | ×1.5 | +10 | 0 | +1, 컨디션 +1 확정 |

어떤 특훈이 뜨는지는 등장 시 랜덤(포지션 60% / 체력 25% / 멘탈 15%). 포지션 특훈의 원점수 총량은 5 × 1.5 × (1+0.7+0.5) = **16.5**로 일반 훈련(8.75)의 약 1.9배.

### 3.5 선택지 비교표 (보통 컨디션, 잠재력 잔여 ≥ 20, 적성 B 기준)

| 선택 | 피로 변화(자연회복 −5 포함) | 부상 위험(피로 60 시점) | 기대 상승(원점수 합) | 기타 |
|---|---|---|---|---|
| 일반 훈련 | 순 +15 | 4.8~9.0% (위험 계수별) | 5.0 + 2.5 + 1.25 = **8.75** × 적성 | |
| 포지션 특훈 | 순 +25 | 10.3% | **16.5** | 힌트 +1 |
| 휴식 | −45 | 0% | mental +1 | 컨디션 +1 (70%) |
| 평가전(자동, T4/8/12) | +12 | 0% (부상 중이면 결장) | 핵심 3스탯 +0~2 | 힌트 +0~3 |

## 4. 성장 수식

### 4.1 턴당 상승치

스탯 `s`에 대해, 훈련 `t`를 선택했을 때:

```
gain_s = B × W_s(t) × A(card, t) × D_s × C(cond) × (1 + S_sup) × (1 + ε)
final_s = min(cur_s + gain_s, potential_s)
```

| 기호 | 의미 | 초기값 |
|---|---|---|
| `B` | 기본 상승치 | **5.0** |
| `W_s(t)` | 훈련 t에서 스탯 s의 가중 | 주 1.0 / 부1 0.5 / 부2 0.25 / 그 외 0 |
| `A(card, t)` | 포지션(카드) 적성 배수 | S 1.30 / A 1.15 / B 1.00 / C 0.70 / D 0.40 |
| `D_s` | 체감 수확 계수 = `clamp(잔여/20, 0.25, 1.0)`, 잔여 = potential_s − cur_s. 잔여 0이면 0 | 4.3절 |
| `C(cond)` | 컨디션 배수 | 절호조 1.25 / 호조 1.10 / 보통 1.00 / 부진 0.85 / 최악 0.65 |
| `S_sup` | 서포트/코치 보정 합 (미채택 시 0) | 0 ~ 0.50 상한 |
| `ε` | 턴 랜덤 편차, 균등분포 | U(−0.25, +0.25). 한 훈련의 세 스탯에 동일 ε 적용(같은 날 컨디션) |

내부는 소수 1자리로 누적하고, 표시는 반올림 정수. 졸업 시 반올림 정수로 확정한다(8.1절).

### 4.2 UI에 노출하는 "예상 상승치"

`ε = 0`으로 계산한 기대값을 훈련 버튼에 `+5.8 / +2.9 / +1.4` 형식으로 표시한다. 랜덤 편차는 "결과가 예상과 다르다"는 재미를 위해 숨기되, 편차 폭(±25%)은 도움말에 명시한다. 부상 확률은 % 정수로 버튼 모서리에 배지(5.4절).

### 4.3 체감 수확 (잔여 잠재력)

| 잔여 잠재력 | ≥ 20 | 15 | 10 | 5 | 3 | 1 | 0 |
|---|---|---|---|---|---|---|---|
| `D_s` | 1.00 | 0.75 | 0.50 | 0.25 | 0.25 | 0.25 | 0 |

잔여 20 이상은 손실 없음, 그 아래부터 선형 감소, 최저 25%. 한 스탯에 몰빵하면 잔여 ~5 이후 턴당 +1.3 수준으로 떨어져 다른 스탯이 상대적으로 매력적이 된다. 이것이 "몰빵 vs 분산"의 핵심 장치다. (더 완만한 곡선 — 잔여 30부터 감소 — 도 시뮬했으나 정책 간 서열이 바뀌지 않고 전체 도달률만 낮아져 초기값은 20으로 둔다. 12절 H2.)

### 4.4 12턴 워크드 예시 — SSR OH

시뮬에서 드러난 사실 두 가지는 밸런싱 가설로 넘긴다(12절 H1, H3):
- "과잉 휴식"이 "최적"과 동급이다. 휴식이 컨디션 +1과 특훈 등장 조건을 함께 챙기므로 **"3훈련 1휴식"이 사실상 최적 리듬**이고, 피로 60 이상에서 밀어붙이는 도박은 EV가 평평하다. 현 룰셋에서 부상은 "전략적 도박"이 아니라 "탐욕(무휴식)과 무지(랜덤)를 벌하는 장치"로 기능한다. 이대로 갈지, 푸시에 양의 EV를 줄지는 프로토타입 체감으로 결정.
- 최적 정책의 OVR 표준편차 1.2는 "반복해도 같은 결과"로 느껴질 수 있다. 분산의 주원인은 컨디션·특훈 등장·MVP 여부이며, 이벤트 결과의 성공/실패 분기(6.2절)를 추가하면 σ 1.5~2.0으로 올라간다.

## 5. 컨디션 · 피로 · 부상

### 5.1 피로 (0~100)

| 원인 | 변화 |
|---|---|
| 일반 훈련 | +20 × 스태미나 계수 |
| 특훈(포지션/체력) | +30 × 스태미나 계수 |
| 멘탈 캠프 | +10 |
| 평가전(T4/T8/T12) | +12 |
| 자연 회복(휴식 아닌 모든 턴 말) | −5 |
| 휴식 | −45 (자연 회복 미적용) |
| 치료(부상 턴) | −20 |
| 이벤트 | −15 ~ +10 |

스태미나 계수 = `1 − (stamina − 60) / 250` → stamina 40: ×1.08, 60: ×1.00, 85: ×0.90, 100: ×0.84. 스태미나가 높을수록 같은 리듬에서 부상 구간 진입이 늦어진다. 이 계수가 스태미나 스탯의 육성 내 존재 이유다.

무휴식 시 피로 궤적: 0 → 15 → 30 → 45 → 60 → 75 → 90 → 100(상한).

### 5.2 컨디션 5단계

| 단계 | 훈련 배수 `C` | 평가전 활약도 보정 | 표시 |
|---|---|---|---|
| 절호조 | 1.25 | +8 | ↑↑ (표정: 기쁨) |
| 호조 | 1.10 | +4 | ↑ |
| 보통 | 1.00 | 0 | → |
| 부진 | 0.85 | −4 | ↓ (표정: 피로) |
| 최악 | 0.65 | −8 | ↓↓ (표정: 좌절) |

시작은 보통. 컨디션은 피로와 별개 변수지만 피로가 높으면 떨어지기 쉽다.

### 5.3 컨디션 드리프트 (매 턴 말, 부상 턴 제외)

| 상황(턴 종료 시 피로) | +1단계 | 유지 | −1단계 |

| 훈련, 피로 < 60 | 15% | 70% | 15% |

이벤트·평가전 보상은 위와 별도로 ±1을 직접 적용.

### 5.4 부상 확률

훈련·특훈 선택 시, **선택 시점의 피로 `f`**로 판정:

```
P_injury = 0 (f < 40)
P_injury = P_max × ((f − 40) / 60)^k × R_train      (f ≥ 40)
P_max = 0.40, k = 1.6
R_train: 서브 0.8 / 리시브 1.0 / 토스 0.7 / 스파이크 1.3 / 블로킹 1.2 / 특훈 1.5 / 휴식·멘탈캠프 0
× (1 − 서포트 부상 방지율)   ← 9절 채택 시
```

| 피로 | 기본(1.0) | 토스(0.7) | 스파이크(1.3) | 특훈(1.5) |
|---|---|---|---|---|
| < 40 | 0% | 0% | 0% | 0% |
| 50 | 2.3% | 1.6% | 3.0% | 3.4% |
| 60 | 6.9% | 4.8% | 9.0% | 10.3% |
| 70 | 13.2% | 9.2% | 17.2% | 19.8% |
| 80 | 20.9% | 14.6% | 27.2% | 31.4% |
| 90 | 29.9% | 20.9% | 38.8% | 44.8% |
| 100 | 40.0% | 28.0% | 52.0% | 60.0% |

UI: 훈련 버튼마다 이 %를 배지로 표시. 0%는 배지 없음, 1~9% 노랑, 10~24% 주황, 25%+ 빨강.

### 5.5 부상 결과

| 구분 | 비율 | 즉시 | 이후 | 표시 |
|---|---|---|---|---|

한 턴에 이벤트 팝업은 최대 1개(평가전 결과 제외). 스킵 버튼은 모든 팝업에 상시 노출.

### 6.2 랜덤 이벤트 풀

- 구조: 본문 ≤ 60자 + 선택지 2개(≤ 12자) + 결과 1줄(≤ 40자) + 효과 배지.
- 선택지 설계 원칙: **"안전한 작은 이득" vs "조건부 큰 이득"**. 정답은 없고 상황(피로·컨디션·남은 턴)에 따라 답이 바뀌어야 한다. 약 30%의 선택지에 성공/실패 분기(성공률 표기)를 두어 분산을 만든다.
- 등장 조건: 턴 범위, 피로 하한/상한, 컨디션, 포지션, 직전 행동. 조건 없는 공용 이벤트가 풀의 60%.
- 런칭 풀 규모: **30개** (훈련 8 / 생활·컨디션 8 / 동료 6 / 팬·외부 4 / 위험 4). 같은 런에서 중복 등장 없음.
- 효과 상한: 스탯 ±3, 피로 ±15, 컨디션 ±1, 힌트 +1, 공용 스킬 획득(위험 카테고리 한정).

데이터 스키마(안):

```
RandomEvent {
  id, weight, category,
  cond: { turnMin, turnMax, fatigueMin, fatigueMax, condMin, positions[], afterAction },
  text (≤60자),
  choices[2]: { label (≤12자), successRate?(0~1),
                onSuccess: { stat{}, fatigue, cond, hint, skillId?, text (≤40자) },
                onFail?:   { ... } }
}
```

### 6.3 카드 스토리 이벤트

- 카드당 **3개**, T2 / T6 / T10 고정 트리거. 1인 개발 물량: 런칭 42명 × 3 = 126개, 컷당 2줄이므로 카드당 ~360자, 총 ~15,000자.
- 각 이벤트는 최대 3컷 + 마지막 컷에 선택지 2개. 두 선택지 모두 이득이되 방향이 다르다(예: 기술 +3 vs 멘탈 +2 & 컨디션 +1). "캐릭터 이해에 맞는" 선택지에 **힌트 +1**이 붙어, 반복 육성 시 정답을 아는 유저가 조금 더 이득을 본다.
- 3개는 기승전결이 아니라 **캠프 초·중·후반의 단면**이다(입소 직후 불안 → 벽에 부딪힘 → 극복/각오). 졸업 후 열리는 카드 스토리(별도 콘텐츠)와 연결.
- N 등급(제네릭 신인)은 공용 스토리 3개를 공유.

### 6.4 인연 이벤트

- 카드 데이터 `bonds[]`(2~3명). T7에 인연 상대가 **로스터(졸업 인스턴스)** 또는 **서포트 슬롯(9절 채택 시)** 에 있으면 발생.
- 효과: 육성 중인 선수 관련 스탯 +2, 힌트 +1, 그리고 리그 모드용 **케미스트리 +5**(두 인스턴스 간, GDD 4절 팀 케미). 인연 상대가 여럿이면 1명 랜덤.
- 텍스트는 인연 쌍당 1개(≤ 60자 2컷). 런칭 시 쌍 수는 30개 내외로 제한.

### 6.5 텍스트 예시 5개

**① 야간 자율 훈련** (조건: 훈련 직후)
> 훈련이 끝났는데 체육관 불이 켜져 있다. 혼자 스파이크를 때리고 있다.
> - [같이 남는다] → spike +2, 피로 +10. 결과: "'감독님, 토스 좀요!' 밤 10시까지 이어진 연습."
> - [그만 쉬게 한다] → 피로 −10, mental +1. 결과: "'…네.' 아쉬운 얼굴로 공을 정리한다."

**② 빗속의 러닝** (조건: T1~T8)
> 새벽부터 폭우. 예정된 외부 러닝을 강행할지 결정해야 한다.
> - [강행한다] (성공 70%) → 성공: stamina +3 / 실패: stamina +1, 컨디션 −1. 결과(성공): "흠뻑 젖은 채 웃는다. '이 정도는 괜찮아요.'"
> - [실내 스트레칭] → speed +1, 피로 −5. 결과: "매트 위에서 조용한 오전. 몸이 가볍다."

**③ 선배의 조언** (조건: 리시브 훈련 직후)
> 구단 선배가 리시브 자세를 봐주겠다고 한다. 지금 폼을 바꾸면 흔들릴 수도 있다.
> - [부탁한다] → receive +3, 힌트 +1, 피로 +5. 결과: "낮은 자세, 무릎 각도. 30분 만에 소리가 달라졌다."
> - [지금 방식대로] → mental +1, dig +1. 결과: "'제 방식이 있어요.' 고집도 재능이다."

**④ 첫 팬레터** (조건: 1차 평가전 이후)
> 구단 앞으로 첫 팬레터가 왔다. 답장을 어떻게 할까.
> - [직접 쓰게 한다] → mental +2, 피로 +5. 결과: "세 번을 고쳐 쓰고 나서야 봉투를 닫았다."
> - [구단이 대신] → 컨디션 +1. 결과: "'…다음엔 제가 쓸게요.' 살짝 붉어진 얼굴."

**⑤ 무릎이 뻐근하다** (조건: 피로 ≥ 60, 위험 카테고리)
> 무릎이 살짝 뻐근하다고 한다. 본인은 괜찮다는데.
> - [정밀 검사] → 피로 −20, 다음 턴 부상 위험 0. 결과: "이상 없음. 안심하고 하루를 쉬었다."
> - [괜찮대요] (성공 60%) → 성공: mental +2, 공용 스킬 '강행군' 힌트 / 실패: 경상 부상. 결과(실패): "다음 날 아침, 계단을 못 내려온다."

## 7. 평가전

### 7.1 배치와 상대

| 회차 | 턴 | 상대(가상) | 상대 강도 | 포맷 | 의미 |
|---|---|---|---|---|---|
| 1차 | T4 | 지역 대학 선발 | **62** | 1세트 25점 | 첫 점검. 대부분 승리하게 설계(성장 체감) |
| 2차 | T8 | 프로 2군 | **72** | 1세트 25점 | 갈림길. 정석 플레이면 50~60% 승 |
| 최종 | T12 | 소속 구단 1군 선발전 | **80** | 1세트 25점 | 클라이맥스. 최적 육성이어야 승률 40~50% |

"강도"는 상대 팀 선수들의 **해당 포지션 핵심 3스탯 평균**을 뜻한다. 시간 예산 때문에 모두 1세트이며, 최종전만 하이라이트 컷을 3장 → 5장으로 늘린다.

### 7.2 시뮬 코어 연동 (인터페이스만 정의)

```
TrainingMatchRequest {
  player:    { position, stats[10] (현재치), condition(5단계), skills[] (이미 보유한 공용 스킬만) },
  teammates: 캠프 동료 NPC 템플릿 6명 (포지션 보완, 강도 = 상대 강도와 동일 → 승패는 주로 육성 선수 활약으로 갈림),
  opponent:  상대 템플릿 7명 (강도 X),
  format:    { sets: 1, pointsToWin: 25 },
  seed
}
TrainingMatchResult {
  won, score,
  playerBox: { attempts, kills, attackErrors, aces, serveErrors, receptions, receptionSuccess, digs, blocks, assists },
  performance (0~100, 활약도),
  highlights[3~5]  // 텍스트 1줄 + SD 토큰 연출 키
}
```

활약도는 시뮬 코어가 박스스코어에서 포지션별 공식으로 산출한다(공식은 match-sim 담당). 이 문서가 요구하는 **보정 목표**는 다음이다:

```
E[활약도] ≈ 50 + (선수 핵심3 평균 − 상대 강도) × 1.5 + 컨디션 보정(5.2절),  σ ≈ 12
```

즉 강도와 동급이면 평균 50, +20 우위면 80(MVP 경계). 위 시뮬 결과(4.5절)는 이 근사로 계산했다.

### 7.3 보상

| 활약도 | 스탯 | 힌트 | 부수 효과 |
|---|---|---|---|
| ≥ 80 (**MVP**) | 핵심 3스탯 +2 | +2 | 컨디션 +1, 다음 턴 특훈 확정, 졸업 화면 MVP 배지 |
| 60~79 | 핵심 3스탯 +1 | +1 | — |
| 40~59 | — | — | — |
| < 40 | — | — | 컨디션 −1 |
| 승리(추가) | — | +1 | 코인 보너스(경제 문서) |
| 패배(추가) | mental +1 | — | — |
| 결장(부상) | — | — | 기록 없음 |

경기 후 피로 +12. 최대 스탯 보상은 3경기 × 2 × 3스탯 = 18점으로, 12턴 훈련 총량(~90 원점수)의 20%. "평가전을 잘 치르면 확실히 다르다"가 느껴지되 훈련을 대체하진 않는 크기다.

## 8. 졸업 판정

### 8.1 최종 스탯 확정

1. 각 스탯 `final_s = round(min(cur_s, potential_s))`, 0~100 클램프.
2. 중상 페널티(−3)는 이미 반영된 상태. 별도 "부상 이력"은 남기지 않는다(단순화).
3. 확정치는 인스턴스에 저장되며 육성 밖에서는 장비/한계돌파로만 변한다(GDD 2.2·7절).

### 8.2 종합 등급 (OVR)

```
OVR = posScale[pos] × Σ_s  w[pos][s] × final_s
```

| 포지션 | serve | receive | set | spike | block | dig | speed | power | stamina | mental | posScale | CORE3 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| S | .10 | .08 | **.30** | .06 | .08 | .08 | .10 | .04 | .04 | .12 | 1.00 | set, mental, speed |
| OH | .10 | **.18** | .04 | **.22** | .08 | .08 | .08 | .10 | .06 | .06 | 1.00 | spike, receive, serve |
| OP | .12 | .05 | .03 | **.28** | .10 | .04 | .08 | .14 | .08 | .08 | 1.00 | spike, power, serve |
| MB | .08 | .04 | .03 | .18 | **.26** | .03 | .10 | .14 | .08 | .06 | 1.00 | block, spike, power |
| L | 0 | **.28** | .06 | 0 | 0 | **.26** | .16 | .04 | .10 | .10 | **0.95** | receive, dig, speed |

각 행의 합 = 1.00. L은 서브·스파이크·블로킹 가중 0이라 약점 스탯이 OVR을 깎지 않아 분포가 위로 치우치므로 `posScale 0.95`로 보정한다(시뮬: 보정 전 최적 83.1 → 보정 후 79.2, 타 포지션과 동급). 포지션 간 형평은 12절 H5.

| 등급 | OVR | 희귀도별 기대(시뮬, 4.5절 정책) |
|---|---|---|
| **S** | ≥ 80 | SSR 최적 3% (서포트 +25% 시 54%), SSR L/MB 최적 ~20% |
| **A** | 74 ~ 79.9 | SSR 최적 97%, SSR 랜덤 53% |
| **B** | 66 ~ 73.9 | SSR 랜덤 47%, SR 최적 90% |
| **C** | 55 ~ 65.9 | SR 랜덤 90%, R 최적 96% |
| **D** | < 55 | R 랜덤 82% |

의도한 메시지: **SSR은 대충 해도 A/B, 잘하면 A 확정, S는 서포트·한계돌파·운의 영역. SR은 잘 키우면 B, R은 잘 키워야 C.** 한계돌파(중복 카드로 potential +3/스탯, GDD 2.2)가 쌓이면 SR도 A에 닿는다.

### 8.3 완성도 (반복 동기용 보조 지표)

- **완성도 % = 핵심 3스탯 도달률**. 등급과 별도로 크게 표시. 같은 카드의 이전 최고 완성도와 비교("자기 최고 갱신!").
- 잔여 잠재력이 남은 스탯을 "미달" 마킹해 다음 육성의 목표를 암시한다.

### 8.4 스킬 획득

스킬 상점·포인트 분배 화면은 **두지 않는다**(우마무스메의 스킬 화면은 회당 수 분을 먹는다). 힌트 포인트를 모으면 졸업 시 자동 해금.

| 조건 | 해금 |
|---|---|
| 힌트 ≥ 3 | 카드 고유 스킬 I Lv1 |
| 힌트 ≥ 6 | 고유 스킬 I Lv2 |
| 힌트 ≥ 9 | 고유 스킬 I Lv3 |
| 등급 A 이상 **그리고** 힌트 ≥ 6 **그리고** 카드 각성 상태(호감도, 10절) | 고유 스킬 II (각성 스킬) |
| 이벤트 획득 | 공용 스킬 최대 2개(예: '강행군', '클러치 서브') |

힌트 공급원: 스토리 정답 선택 3 + 평가전 활약 0~2 × 3 + 승리 +1 × 3 + 특훈 +1 + 인연 +1 + 랜덤 이벤트. 시뮬 평균: 최적 7.9(Lv2 안정, Lv3 30%), 랜덤 5.9(Lv1 안정). 스킬 효과 정의는 match-sim 담당.

### 8.5 졸업 화면

순서(총 40초, 어디서든 탭으로 넘김):
1. **스탯 리빌** — 10개 바가 초기값에서 최종값으로 차오름(2초), 상한 도달 스탯은 "MAX" 스탬프.
2. **등급 스탬프** + OVR + 완성도 %. 등급별 코멘트 2줄, 스탠딩 표정(S/A 기쁨, D 좌절).
3. **해금 스킬** 카드 팝(있을 때만).
4. **캠프 기록** 1줄: "평가전 3승 0패 · MVP 1회 · 부상 0회 · 절호조 4턴".
5. **보상** — 코인, 강화 소재, 카드 호감도 +10, 스카우트 평판(10절).
6. **인스턴스 비교** (같은 카드의 기존 인스턴스가 있을 때, 8.6절).
7. **버튼**: [로스터로] [같은 카드로 한 번 더 (스태미나 30)] [다른 선수 육성] [공유].

### 8.6 재육성 시 인스턴스 비교 흐름

```
졸업 화면 6단계
 ├─ 기존 인스턴스 없음 → 자동 로스터 편입 (비교 화면 생략)
 └─ 기존 인스턴스 있음 → 비교 화면
       좌: 기존(대표) | 우: 신규
       OVR · 등급 · 완성도 · 스탯 10종(▲▼ 색), 스킬 목록, 케미 보너스(기존만 보유)
       [신규로 교체]  → 기존은 보관함으로 이동
       [신규를 보관]  → 대표는 기존 유지, 신규는 보관함
       [신규 방출]    → 강화 소재 환급 (등급별)
```

- 카드당 **대표 인스턴스 1개**만 로스터·PvP에 쓰인다. 보관함은 계정당 10칸(확장 가능), 보관 인스턴스는 언제든 대표로 승격/방출 가능.
- 케미스트리·인연 누적치는 **인스턴스에 귀속**된다. 교체 시 "케미 초기화" 경고를 띄운다(리그 매니지먼트와의 긴장 요소).
- 비교 화면은 "OVR만 보고 교체"가 아니라 "스파이크 특화 vs 리시브 특화"처럼 **빌드가 다른 인스턴스를 상황별로 보관**하게 유도한다(리그 상대에 따라 대표 교체).

## 9. 서포트/코치 시스템 (제안 — 채택 여부 열린 결정)

### 9.1 필요성

- 수식의 `S_sup`와 부상 방지율은 자리만 있고 값이 0이다. 시뮬상 **S 등급은 서포트 없이는 3%**, +25%면 54% — 즉 서포트가 "S의 열쇠"가 되어 수집 2축의 상품 가치가 자연스럽게 생긴다.
- 반면 1인 개발·10분 제약에서 제2 수집축은 콘텐츠·UI·밸런싱 부담을 두 배로 만든다.

### 9.2 후보 3안

| | A. 코치 카드 가챠 (우마 서포트형) | B. 선배 서포트 (기존 로스터 활용) | C. 비가챠 스태프 (성장형) |
|---|---|---|---|
| 개요 | 별도 카드풀(코치·트레이너·스카우트). 가챠 2축 | 졸업한 **내 선수 인스턴스**를 서포트 슬롯에 편성. 인연·포지션 매칭 보정 | 구단 스태프 4명 고정, 재화로 레벨업 |

### 9.3 채택 시 공통 규격 (A/B 모두 적용)

| 효과 유형 | 값(카드 등급별) | 수식 연결 |
|---|---|---|
| 훈련 보정 | 특정 훈련 1종 +5 / +10 / +15% | `S_sup` 가산 (합계 상한 +50%) |
| 부 스탯 추가 | 특정 훈련에 부 스탯 3 추가 (×0.25) | `W_s(t)` |
| 특훈 유도 | 특훈 등장 +5 / +10 / +15%p | 3.4절 |
| 부상 방지 | 부상 확률 ×0.9 / ×0.8 / ×0.7 | 5.4절 (합계 하한 ×0.5) |
| 피로 경감 | 훈련 피로 −2 / −3 / −5 | 5.1절 |
| 이벤트 | 코치 고유 이벤트 1~2개 (힌트·스탯) | 6절 상한 안에서, 랜덤 슬롯 대체 |
| 인연 | 인연 상대면 T7 인연 이벤트 확정 | 6.4절 |

**편성 30초 상한**을 지키기 위해 [추천 편성] 버튼(포지션 핵심 훈련 보정 우선) + 마지막 편성 기억은 필수다.

### 9.4 권장

- Phase 1(코어 프로토타입)은 **서포트 없이** 육성 루프만 검증한다(`S_sup = 0`).
- Phase 3(경제) 착수 전 결정. 1인 개발 조건에서는 **B안(선배 서포트)을 기본**으로 하고, 라이브 운영 여력이 생기면 A안(코치 카드)을 얹는 순서를 권장한다. B안은 "중복 카드 = 한계돌파 + 서포트 인스턴스"로 선수 가챠의 가치를 올리면서 아트 물량이 0이다.

## 10. 재화 · 스태미나 연결 (개요)

세부 수치는 경제 문서에서 확정. 여기서는 육성 루프가 요구하는 골격만 둔다.

| 항목 | 초기값 | 근거 |
|---|---|---|
| 육성 1회 비용 | 스태미나 **30** | 상한 120 = 4회 연속. 6분당 1 회복 → 하루 240 = 8회(≈ 80분) |
| 무과금 일일 기대 | 3~4회(30~40분) | 자연 회복 + 일일 미션 스태미나 30 |
| 졸업 보상 | 코인(등급별 D 300 → S 1,500), 강화 소재, 카드 호감도 +10, 스카우트 평판 +등급점수 | 코인은 장비·스태프, 소재는 한계돌파 |
| 카드 호감도 | 같은 카드 육성 10회(100)로 각성(각성 일러스트·스킬 II 조건) | "같은 카드를 또 키우는" 명분 |
| 스카우트 평판 | 육성 누적 점수. 시즌 랭킹·미션 재화 | 반복 자체가 진행이 되게 |

**반복 루프**: 육성(30 스태미나) → 새 인스턴스 → 로스터 OVR ↑ → 리그/PvP 승리 → 재화·소재 → 한계돌파(potential ↑) → 같은 카드 재육성으로 더 높은 상한 → …

유료 접점: 스태미나 회복, 코치 카드 가챠(9절 A안 시), 코스튬. **부상 방지권·컨디션 드링크 같은 "육성 내 소모품" 판매는 P2W 인상이 강해 열린 이슈**로 둔다(무료 재화 구매만 허용하는 절충안 포함).

## 11. UX 흐름

### 11.1 화면 시퀀스

```
[육성 홈] 카드 선택(포지션 필터, 잠재력 미리보기, 기존 인스턴스 OVR 표시)
   → [편성] 코치/서포트 슬롯(채택 시) · 추천 편성 · 시작 (스태미나 −30)
   → [캠프 인트로] 1컷 (탭 스킵)
   → [턴 화면] ×12
        ├ 상단: 주차 12칸 타임라인(평가전 아이콘), 피로 게이지, 컨디션 화살표, 스탠딩
        ├ 중앙: 스탯 10종 바(현재/잠재력, 잔여 게이지), 탭하면 상세
        └ 하단: 훈련 5 버튼(예상 상승치 3줄 + 적성 아이콘 + 부상 % 배지) · 휴식 · 특훈(등장 시 강조)
      → [결과 팝업] 숫자 배지 + 플레이버 1줄 (2초 자동 진행, 탭 스킵)
      → [이벤트 팝업] (있을 때) 본문 2줄 + 선택 2
      → [평가전] (T4/8/12) 자동 시뮬 → 요약 카드(스코어·박스·활약도·보상), [관전] 옵션은 랠리 로그 재생(언제든 스킵)
   → [졸업] 8.5절
   → [비교] 8.6절 → [육성 홈] 또는 [한 번 더]
```

### 11.2 스킵 · 자동 옵션

| 옵션 | 동작 | 대상 |
|---|---|---|
| 연출 스킵(기본 ON 가능) | 결과 팝업 즉시, 평가전 요약만, 스토리 1컷 요약 | 재육성 2회차부터 노출 |
| 자동 진행(AI 코치) | "3훈련 1휴식 + 가중 상승 최대 훈련 + 특훈 우선" 휴리스틱(12.3절 최적 정책과 동일)으로 12턴 자동. 이벤트는 사전 설정(안전/공격) 규칙으로 자동 선택. 언제든 수동 개입 | 튜토리얼 완료 후. 결과는 수동 최적의 ~95% |
| 평가전 결과 스킵 | 요약 카드만 | 항상 |

자동 진행이 수동과 차이가 없으면 수동의 의미가 사라지므로, 자동은 **이벤트 선택에서 항상 "안전" 옵션을 고르고 특훈 등장에 반응하지 않는** 정도의 핸디캡을 둘지 열린 이슈(13절)로 둔다.

### 11.3 "한 번 더" 유도 장치

1. 졸업 화면 최상단에 **자기 최고 기록 비교**("이전 최고 OVR 77.1 → 이번 79.4, 갱신!").
2. **미달 표시**: 잠재력을 남긴 핵심 스탯을 빨간 점선으로. "리시브 잔여 1.4".
3. **미해금 표시**: 스킬 II·스토리 정답 미획득·인연 미발생을 자물쇠 아이콘으로.
4. [한 번 더] 버튼에 스태미나 잔량과 다음 회복 시각 표시. 편성 기억으로 3탭 만에 재시작.
5. 호감도 게이지(10회 각성)를 졸업 보상 단계에서 채우는 연출.
6. 첫 육성은 **"완주 보상"(가챠 티켓 1)** 을 졸업 화면에서 지급해 루프 1회를 무조건 경험시킨다.

## 12. 밸런싱 가설과 검증 방법

### 12.1 시뮬레이션으로 확인할 지표 (코드 프로토타입 전)

| # | 가설 | 지표 | 목표 | 현재 시뮬 값 |
|---|---|---|---|---|
| H1 | 최적 플레이가 랜덤을 뚜렷이 이긴다 | OVR 차, 핵심 도달률 차 | OVR ≥ 4, 도달률 ≥ 25%p | 4.0 / 29%p ✓ |
| H2 | 몰빵보다 분산이 낫다 | 단일 훈련 반복 vs 최적 | 최적 ≥ 몰빵 + 3 | +3.9 ✓ |
| H3 | 휴식 타이밍에 의미 있는 선택이 있다 | 과잉 휴식 vs 최적 | 최적 ≥ 과잉휴식 + 0.7 | **−0.1 ✗** (4.5절 논의) |

| H6 | 반복 결과가 다르다 | 최적 정책 OVR σ, 등급 분포 | σ 1.5~2.0 | **1.2 (미달)** |
| H7 | 희귀도 사다리 | R/SR/SSR 최적 등급 | C / B / A | ✓ |
| H8 | 힌트 경제 | 최적 평균 힌트 | 6~8 (Lv2 안정) | 7.9 ✓ |

H3 후보 레버(하나씩 시뮬): (a) 휴식 컨디션 +1 확률 70% → 40%, (b) 특훈 등장 조건을 "피로 ≤ 40"에서 "컨디션 호조↑"만으로, (c) 피로 50~79 훈련 효율 +10%(시뮬: 효과 미미, 체감용), (d) 잠재력 잔여 곡선 완화(전체 도달률 하락 부작용). H6 후보 레버: 이벤트 성공/실패 분기 비중 30% → 50%, 컨디션 배수 폭 확대(절호조 1.30 / 최악 0.60).

### 12.2 코드 프로토타입(Phase 1)에서 검증할 항목

- [ ] 턴당 결정 시간 로그: 평균 ≤ 27초, 90퍼센타일 ≤ 45초. 초과 시 정보 밀도(예상 상승치 3줄 → 주 스탯 1줄) 조정.
- [ ] 1회 완주 시간: 수동 ≤ 10분, 스킵 ≤ 2.5분, 자동 ≤ 4분.
- [ ] 이벤트 스킵률: 랜덤 이벤트 본문을 읽지 않고 선택하는 비율. 50% 초과면 텍스트 상한을 1줄로.
- [ ] 부상 배지의 행동 변화: 배지 10% 이상에서 훈련 선택 비율. "위험을 읽고 있는지" 확인.
- [ ] 평가전 관전 선택률과 이탈: 관전을 고른 유저의 완주율.
- [ ] "한 번 더" 클릭률: 졸업 화면에서 즉시 재육성 비율 ≥ 40%(목표).
- [ ] 활약도 보정: 시뮬 코어 박스스코어 → 활약도의 평균·분산이 7.2절 근사와 ±5 이내인지.
- [ ] 스킬 해금 분포: 실플레이 힌트 평균이 시뮬(7.9)과 ±1 이내인지.

### 12.3 시뮬 정책 정의 (재현용)

> 이 문서의 수치(워크드 예시, 정책별 등급 분포, 부상률)는 `tools/training-sim/train_sim.py`(문서 상수를 1:1로 구현한 파이썬 몬테카를로, n=5,000)의 출력이다. `python3 tools/training-sim/train_sim.py`로 재현할 수 있으며, 상수를 바꿔 본 뒤 문서를 갱신하는 순서로 튜닝한다. C# 육성 로직 구현 시 테스트 오라클로 사용한다.

- **최적 휴리스틱**: 특훈 등장 & 피로 ≤ 45 → 특훈. 아니면 `Σ w[pos][s] × E[gain_s]`가 최대인 훈련을 고르되, 그 훈련의 부상 확률 > 8%이고 T12가 아니면 휴식.
- **과잉 휴식**: 피로 ≥ 35이면 휴식(T12 제외), 아니면 가중 최대 훈련. 특훈은 항상 수락.
- **무휴식 몰빵**: 항상 가중 최대 훈련(특훈 수락).
- **랜덤**: 훈련 5 + 휴식 (+ 특훈 등장 시) 균등.
- **스파이크만**: 피로 ≥ 55면 휴식, 아니면 스파이크.
- 공통: 스토리 이벤트는 정답 선택(힌트 +1), 랜덤 이벤트는 스탯 +1~3(50%) / 피로 ±(25%) / 컨디션 ±1(25%)의 평균 효과, 평가전 활약도는 7.2절 근사식.

시뮬레이터 자체(파이썬 ~250줄)는 이 문서 규칙의 1:1 구현이며, Phase 1의 C# 육성 로직을 짤 때 테스트 오라클로 옮겨 쓸 수 있다.
