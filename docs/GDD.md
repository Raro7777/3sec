## 1. 핵심 판타지 & 코어 루프

**핵심 판타지**: "나는 신생 구단의 감독 겸 스카우터다. 재능은 있지만 다듬어지지 않은 신인을 스카우트하고, 직접 훈련 스케줄을 짜서 세계 최고의 선수로 키운 뒤, 내가 설계한 로테이션과 전술로 리그 우승을 노린다."

**코어 루프 (한 사이클)**

```
스카우트(가챠)
   → 육성 시즌 진입 (신인 카드 1명, 턴제 육성)
   → 육성 종료("졸업") → 로스터 정식 편입, 능력치 확정
   → 팀 편성 (라인업 / 로테이션 / 전술)
   → 리그·대회 경기 시뮬레이션
   → 보상 획득 (재화, 강화 소재, 신규 선수 조각 등)
   → 재화로 재스카우트 / 기존 선수 강화 → 루프 반복
```

이중 루프 구조로 설계한다:
- **단기 루프(세션당 5~15분)**: 육성 턴 진행, 연습경기, 일일 미션
- **중기 루프(1~2주)**: 한 선수의 육성 시즌 완주, 리그 한 시즌 진행
- **장기 루프(시즌/이벤트 단위)**: 팀 완성도 상승, 랭킹 등반, 신규 캐릭터 픽업 이벤트

## 2. 캐릭터(선수 카드) 시스템

### 2.1 포지션 (배구 고유 룰 반영)

| 포지션 | 약자 | 역할 |
|---|---|---|
| 세터 | S | 토스 배급, 팀 공격 설계의 핵심. 팀 전체 공격 성공률에 배수 영향 |
| 아웃사이드 히터(윙스파이커) | OH | 주공격수, 리시브도 겸함 |
| 아포짓 스파이커 | OP | 후위 공격 전담, 리시브 부담 적고 순수 화력형 |
| 미들블로커 | MB | 속공 + 블로킹의 핵심, 높이 스탯 중요 |
| 리베로 | L | 수비 전담, 후위 한정 출전, 서브 불가 등 실제 룰 반영 |

### 2.2 희귀도 & 성장

- 등급: N → R → SR → SSR (+ 한정/픽업 등급)
- 스탯: 서브, 리시브, 토스(세트), 스파이크, 블로킹, 디그, 스피드, 파워, 스태미나, 멘탈(클러치)
- 잠재력(Potential) 상한 + 한계돌파(중복 카드로 상한 해제) 구조
- 개인 특기 스킬(패시브/트리거형): 예) "타임서브 성공 시 다음 랠리 리시브 확률 +", "2단 연속 실점 시 정신력 발동으로 공격력 회복" 등 배구 특유의 리듬을 스킬화

### 2.3 성장 서사 (인연/스토리)

- 선수별 개인 스토리 이벤트(육성 중 발생)
- 팀 동료 간 "인연 보너스"(듀오/트리오 시너지) — 특정 선수 조합 로스터 편성 시 스탯 보너스

## 3. 육성 모드 (메인 콘텐츠)

우마무스메형 "턴제 육성"을 배구에 맞게 각색.

- **시즌 구조**: 예) 총 N턴(주 단위) 육성 시즌. 매 턴 선택지:
  - 개별 훈련(서브/리시브/토스/스파이크/블로킹 중 선택, 스탯 상승 + 피로도 누적)
  - 휴식(피로도 회복, 컨디션 관리)
  - 특훈 이벤트(랜덤/조건부 발생, 큰 상승폭 + 리스크)
  - 연습경기(중간 점검, 팀워크 스탯 상승)
- **컨디션 · 피로도 · 부상 리스크**: 무리한 훈련 스택 시 부상 확률 상승 → 이후 시즌 결장/스탯 페널티
- **평가전**: 육성 중간중간 배치되는 미니 매치로 성장 체감 제공 (모의고사 개념의 배구 버전)
- **졸업**: 육성 시즌 종료 시 스탯 확정, 팀 로스터에 정식 편입되어 이후 리그 모드의 영구 자산이 됨

---

## 4. 팀 매니지먼트 (감독 파트)

- **로스터**: 출전 6인 + 리베로 + 벤치(교체 자원)
- **라인업/로테이션**: 배구 고유 규칙 반영 — 시계방향 로테이션, 서브 순서, 리베로 전담 교체 규칙, 세트당 교체 횟수 제한 등을 시스템으로 구현해 "배구다움"을 매니지먼트 재미로 승화
- **전술 슬라이더**: 공격 전개 비중(속공/시간차/이동공격/후위공격), 리시브 포메이션, 서브 전략(강서브 vs 안정서브)
- **팀 케미스트리**: 세터-공격수 호흡도(함께 뛴 경기 수로 누적), 인연 보너스 반영

---

## 5. 경기 시뮬레이션

- **표현 방식**: 실시간 3D 렌더링 대신, 2D 심플 연출(코트 위 아이콘 애니메이션) + 랠리 단위 텍스트/로그 중계. 연출 비용을 통제하면서도 몰입감 확보 (모바일 매니저 게임의 표준 해법)
- **세트 규칙**: 5세트 3선승, 랠리포인트제, 25점(5세트 15점), 2점차 승리 등 실제 배구 규칙 반영
- **랠리 판정 체인(개념)**: 서브 → 리시브 → 토스 → 공격(스파이크/속공) → 블로킹/디그 순으로 단계별 스탯 대결 + 확률 + 스킬 발동을 계산해 득실점 결정. 각 단계 결과가 다음 단계 성공률에 영향을 주는 연쇄 구조로, 배구 특유의 "랠리 흐름"을 재현
- **변수**: 컨디션, 클러치(접전 상황 멘탈 스탯), 팀워크, 관중/원정 보정 등

---

## 6. 시즌 / 리그 구조

- 정규 시즌(자동 진행 지원 + 수동 관전 선택 가능), 순위표, 승강 여부는 추후 결정
- 컵대회·챔피언십 등 별도 대회
- **PvP**: 비동기 대전(상대 유저 팀 스냅샷과 서버 시뮬레이션으로 대결) — 실시간 대전은 1차 범위에서 제외
- 시즌제 랭킹 및 시즌 보상

---

## 7. 수집(가챠) & 경제

- 재화: 무료 재화 / 유료 재화 / 육성 소재 / 강화 소재로 분리
- 가챠에는 확률 표기 + 천장(픽업 보장) 시스템 적용 (국내 확률형 아이템 표시 의무 규정 준수 전제)
- 장비/굿즈 아이템으로 부가 스탯 보정

---

## 8. 소셜 / 라이브옵스

- 친구 방문, 다른 유저 선수 "게스트 초빙"(서포트) 개념 검토
- 길드(구단 연합) 및 길드 단위 콘텐츠
- 시즌 이벤트, 신규 선수 픽업, 스토리 이벤트 주기적 공급

---

## 9. 아트 / 톤

- 카툰/애니메 스타일 캐릭터 일러스트, 밝고 청춘 스포츠물 톤
- 팀별 유니폼·컬러 아이덴티티로 수집 동기 부여
- 세계관·캐릭터는 완전 오리지널로 설계(특정 스포츠 만화·실제 인물 오마주 지양, 저작권 리스크 회피)

---

## 10. 수익 모델

- F2P + 가챠(캐릭터/코스튬) 표준 모델
- 시즌패스(배틀패스형), 스태미나 회복/시간단축 아이템
- 세부 가격·확률 정책은 별도 밸런싱 문서에서 확정

## 11. 기술 스택 (제안, 미확정)

| 옵션 | 장점 | 단점 |
|---|---|---|
| Flutter | 단일 코드베이스로 iOS/Android, 카드/UI 중심 게임에 적합, 빠른 개발 | 커스텀 2D 연출은 별도 렌더링 레이어 필요 |
| React Native | 웹 기술 재사용, 인력 수급 용이 | 게임 특화 렌더링/애니메이션은 라이브러리 의존도 높음 |
| Unity(2D) | 게임 특화, 연출/애니메이션 자유도 최고 | 카드 UI·리스트 위주 화면은 상대적으로 개발 속도 느림, 빌드 용량 큼 |

경기 시뮬레이션은 부정 방지(PvP 랭킹) 및 밸런스 패치 유연성을 위해 **서버 권위(server-authoritative) 시뮬레이션**을 권장. 클라이언트는 서버가 계산한 결과를 재생(replay)하는 방식.

→ 다음 세션에서 팀 규모(1인 개발 여부)·예산·목표 출시 기간을 확인한 뒤 최종 스택을 확정하는 것을 권장.

## 12. MVP 로드맵

- **Phase 0 — 기획 확정**: 스탯 공식, 포지션별 역할 밸런스, 아트 스타일 가이드 확정
- **Phase 1 — 코어 프로토타입**: 선수 1명 육성 루프 + 단일 경기 텍스트 시뮬레이터 (아트 없이 로직 검증)
- **Phase 2 — 매니지먼트 계층**: 로스터/라인업/로테이션 + 리그 시즌 진행
- **Phase 3 — 경제/서버**: 가챠, 재화 시스템, 서버 연동, 비동기 PvP
- **Phase 4 — 라이브옵스**: 이벤트, 신규 캐릭터 파이프라인, 폴리싱, 스토어 출시 준비
