# 선수 이야기 (프로토타입 v0.1, 2026-10)

> 근거: [reports/육성 게임 애착 설계 분석.md](../reports/육성%20게임%20애착%20설계%20분석.md) — "애착은 대사량이 아니라 회수 구조에서 생긴다".
> 데이터: `web/engine/stories.js` · 연출: `web/app-shell.html`(선수 이야기 블록) · 성장 아크(벽 → 모의고사 → 증명 컷인 → 그때 vs 지금) 위에 얹는다.

## 공식

**결함 한 줄 → 캠프에서 드러나는 장면 → 감독의 말(선택) → 리그 경기에서 바로 그 기술로 회수.**

| 선수 | 벽 | 결함 | 꿈 |
|---|---|---|---|
| 노예서 (가온 OH) | 스파이크 | 수첩엔 선배 플레이뿐, 자기 공격은 한 줄도 없다 | 누군가의 수첩에 내 공격이 적히는 것 |
| 석누리 (태령 MB) | 블로킹 | "블로킹은 새봄 언니 거" — 막는 걸 피해 손이 늦다 | 석누리라는 이름으로 불리는 것 |
| 인초원 (해솔 MB) | 서브 | 혼자가 되는 순간(서브)에 다리가 굳는다 | 고향 가게 TV에 내 서브가 나오는 것 |

## 한 선수의 데이터

- `wall` — 성장 아크의 벽(자동 '최저 능력치' 대신 프로필의 결함).
- `flaw` / `dream` — 캠프 벽 띠 · 주인공 고르기 · 그때 vs 지금에 인용.
- `beats[3]` — 스토리 3컷(턴 2·6·10)의 제목·본문·선택지 문구·반응. **선택지 순서·효과는 원본(training-events.js) 그대로** → 육성 캘리브레이션 불변.
- `right` — 그 선수가 기다린 말(이해 테스트). 맞히면 환호 표정 + "마음이 통했다", 틀려도 손실 없음(샤니마스 약속의 역전 인센티브 회피).
- `evalNote` — 첫 모의고사(벽 테스트) 문장. `then` — 그때 vs 지금의 '그때'.
- `proof.title` / `proof.sub[2]` — 증명 컷인. **sub 는 이야기 3에서 고른 말을 회수한다.**
- `next` — 다음 이야기 예고. `endings[3]` — 졸업 등급(S·A / B / C 이하)별 종료 장면. 실패에도 장면을 준다.

## 장면 재생 (VN 씬)

- 스토리 3컷은 전체 화면 **VN 씬**으로 재생한다: 캠프 장면 배경 + 선수 상반신(카드에서 오림) + 대사창. 한 줄씩 타자 효과, 탭해서 진행.
- 줄 맨 앞 `[cheer]`/`[sad]`/`[focus]` 에서 상반신이 **표정 얼굴**(카드 표정 시트)로 바뀐다. `"…"` 로 시작하면 선수의 말(이름표), 아니면 지문.
- 마지막 줄 뒤에 선택지(이야기 선수는 능력치 표기 없음, 아키타입 선수는 작은 효과 배지 + 추천). 선택 → 반응 줄 → 💗 마음이 통했다 / 조금 다른 말 → 계속.
- 이야기 없는 선수도 같은 씬을 쓴다(한 문단을 문장 단위로 나눠 재생).
- 졸업: 등급 리빌 뒤 **캠프의 끝** 씬(등급별 종료 줄) → 졸업식 화면.
- 연출 끔(`bloom-fx-off`, 회귀 테스트)이면 씬 없이 인라인 선택지만 — `app-test` 흐름 불변.
- 에피소드 트랙(1화·2화·3화·졸업·증명)이 캠프 벽 띠·졸업 카드·감독실 "진행 중인 이야기" 카드에 붙는다. 💗 = 마음이 통한 화.
- 경기 인트로: 주인공이 선발이고 벽을 넘을 준비가 됐으면 "📖 최종화 — ○○의 벽. 오늘, 증명할 차례." 한 줄.

## 연출 규칙

- 컷인은 실제 경기 이벤트(그 능력치가 관여한 실제 성공)에서만 — 대사가 데이터와 어긋나지 않게.
- 스토리 선택 직후 반응 장면(얼굴 + 대사)을 크게 띄운다. 이야기 없는 선수도 원본 결과 문장으로 같은 장면을 본다.
- 이야기 선수의 스토리 컷에는 '추천'을 띄우지 않는다(이해 테스트와 충돌).
- 체험용: 육성 탭 "이야기가 있는 선수" 배너로 3명 중 1명을 **1회 무료**로 데려온다(보유하지 않았을 때만). 스카우트로도 그대로 나온다.
