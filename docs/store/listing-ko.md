# Play 스토어 등록 문구 (한국어)

## 앱 이름 (30자 이내)
```
가난한자의 FM
```

## 간단한 설명 (80자 이내)
```
2부 리그 꼴찌 구단의 감독. 전술을 짜고 라커룸에서 한마디 하고, 90분을 지휘합니다.
```
(39자)

## 자세한 설명 (4000자 이내)
```
돈 없는 구단의 감독이 되었습니다.

가난한자의 FM은 2부 리그 최하위권 구단을 맡아 승격과 우승까지 끌고 가는 축구 감독
게임입니다. 선수를 사 모으는 게임이 아니라, 있는 선수로 버티고 이기는 게임입니다.

■ 경기를 직접 지휘합니다
20Hz로 도는 물리 기반 엔진 위에서 90분이 실제로 흘러갑니다. 중계 화면처럼 스코어보드와
하단 자막이 붙고, 골이 터지면 리플레이가 돌아갑니다. 전반 45분을 보고 포메이션을 바꾸거나,
선수를 빼거나, 마지막 10분에 총공격을 지시할 수 있습니다.

■ 라커룸에서 하는 말이 경기를 바꿉니다
킥오프 전, 하프타임, 경기가 끝난 뒤 — 세 번 선수들 앞에 섭니다. 격려·침착·요구·질책 중
무엇을 고르느냐가 선수들의 사기를, 사기가 그날의 능력치를 움직입니다.

좋은 말만 해서는 안 됩니다. 어떤 말이 얼마를 주는지는 정해져 있지 않고, 그 상황에서 할 수
있었던 네 마디의 평균을 얼마나 넘었느냐로 정해집니다. 같은 말을 세 번 반복하면 효과가
0에 닿았다가 마이너스로 돌아섭니다. 야심가는 도전받기를 원하고, 다혈질은 질책을 개인적으로
받아들이고, 프로페셔널한 선수는 무슨 말을 해도 덜 흔들립니다.

■ 감독실에서 시작합니다
메뉴가 아니라 방입니다. 벽의 전술판이 다음 상대를, 책상의 신문이 리그 판도를, 울리는
전화기가 들어온 이적 제안을 말해 줍니다. 창밖으로는 오늘 밤의 홈구장이 보입니다.

■ 그 밖에
· 2개 디비전 24개 구단, 홈·원정 22라운드, 컵 대회, 동아시아 챔피언스리그
· 선수마다 성격과 사기, 유스 아카데미, 이적 시장과 계약 협상, 외국인 규정
· 이사회 신뢰도와 경질, 그리고 다른 구단의 감독직 제안
· 7가지 시나리오 모드 — 빚더미, 유스만으로, 매각 지시, 우승 도전
· 트로피 진열장과 기록실에 쌓이는 커리어

■ 약속
· 광고 없음
· 인앱 결제 없음
· 계정 없음, 로그인 없음
· 인터넷 연결 없이 완전히 동작합니다
· 어떤 데이터도 수집하지 않습니다
```
