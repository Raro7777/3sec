# 코어 루프 v2 — "내가 키운 선수가 리그에서 활약한다" (방향 문서)

> 상태: **v0.1 (방향 설정, 2026-10).** 테스터(=기획자) 결정으로 게임의 중심을 **② "리그를 보상 무대로, 육성을 희소하게"** 로 잡는다.
> 이 문서는 수치 스펙이 아니라 **큰 그림(정체성·코어 루프·시간축·경제 방향)과 단계 계획**이다. 확정 수치는 각 단계에서
> [training-mode.md](training-mode.md)·[league-and-economy.md](league-and-economy.md) 에 반영하고 하네스(`season-check`)로 재검증한다.
> 배경: 육성(결정·깊이)과 리그(관전·얕은 개입)가 **평행하게 겹쳐 돌아** "노력과 목표가 따로 논다"는 문제의식(2026-10 논의).

## 0. 한 줄 정체성

**짧은 육성으로 빚은 '내 선수'가, 리그라는 무대에서 활약하는 걸 보는 게임.**
- 육성 = *작가가 주인공을 빚는* 단계(희소·결정 깊음).
- 리그 = *그 주인공이 활약하는 연재* 단계(관전이지만 **인과·서사로 크게 보상**).
- 수집(가챠)은 원석 공급, 노화는 다음 프로젝트 수요 — 둘 다 이 축을 돌리는 바퀴.

경쟁 지형에서의 자리: 우마무스메(깊지만 1회 40~60분, 무거움)와 순수 수집형(자동 전투, 육성 얕음) 사이.
**우리만의 것 = 짧은 육성(10분) × 보이는 인과 × 선수와의 유대.** 모바일 "짧게 여러 번" 리텐션과 맞물린다.

## 1. 지금 왜 어긋나는가 (고칠 것)

| # | 증상 | 원인 |
|---|---|---|
| 1 | 육성과 리그가 '따로 논다' | 성격이 다른 두 루프(결정형 vs 관전형)가 **시간축에서 겹쳐** 평행 운행. 프리시즌에도 육성+평가전, 시즌에도 매치데이마다 육성+경기 |
| 2 | 육성이 '의미 없다' | 육성 한계 상승(+2~3 OVR)이 **리그 결과를 극적으로 못 바꿈** → 수확 체감이 약함 |
| 3 | 리그가 '내 것 같지 않다' | 경기는 시뮬이 돌리고 나는 본다 → **"내가 키운 게 쓰였다"는 체감**이 약함 |
| 4 | 한 판의 무게가 없다 | 재육성이 '더 좋을 때만 교체'라 **부담 없이 계속 리롤** → 결정의 긴장이 희석 |

→ 핵심 진단: **우리 강점(짧은 육성 → 보이는 인과)이 반쪽만 구현돼, 두 개의 반쪽 루프가 됐다.**

## 2. 코어 루프 (v2)

```
스카우트(원석 발굴)
   → 육성  : '프로젝트 선수'를 만든다 — 희소하고 결정이 깊다(씨 뿌리기)
   → 리그  : 만든 선수가 무대에서 활약 — 인과·서사로 크게 보상(수확)
   → 결산  : 내가 키운 선수들의 스토리·성장·기록
   → 노화  : 전성기가 지나면 다음 프로젝트가 필요
   ↑───────────────────────────────── 반복
```

바뀌는 축: 육성은 **자주 하는 잡일이 아니라, 주인공을 빚는 의식(ritual)** 이 된다. 리그는 **또 하나의 게임이 아니라, 육성의 보상 무대** 가 된다.

## 3. 시간축 재설계 — 짓기(BUILD)와 겨루기(COMPETE)를 가른다

| 구간 | 성격 | 플레이어가 하는 일 |
|---|---|---|
| **프리시즌(BUILD)** | 육성 창구 | 이번 시즌의 **프로젝트 선수**를 만든다/보강한다. 육성의 깊은 결정은 여기 집중 |
| **시즌(COMPETE)** | 무대 | 만든 선수로 14매치데이를 **치르며 본다.** 깊은 캠프는 돌지 않고, 있어도 **가벼운 중간 조정**(1~2회) 정도 |
| **결산(HARVEST)** | 서사 | 내가 키운 선수들의 시즌 스토리·성장·통산. 다음 프로젝트 예고 |

핵심: **매치데이마다 또 캠프를 도는 중복을 없앤다.** 이게 #1(겹침)과 #4(무게 없음)를 동시에 푼다.
(현재는 매치데이마다 "먼저 육성하기"로 풀캠프 가능 — 이걸 프리시즌 집중 + 시즌 중 경량 조정으로 분리.)

## 4. 세 기둥

### 4.1 육성을 희소하고 무겁게 (씨 뿌리기)
- 시즌당 **프로젝트 슬롯 제한**(예: 2~3명) — 아무나 무한 리롤이 아니라 "이번 시즌 누구를 빚을까"의 선택.
- **재육성 리롤 그라인드 억제**: 비용 또는 횟수 제한을 둬서 한 판 한 판에 무게. ("더 좋을 때만 교체"의 공짜 반복 완화)
- 효과: 각 캠프가 **한 명의 주인공**을 만든다 → 유대가 생긴다.
- ⚠ **경제·난이도 직결(캘리브레이션 필요).** 육성 빈도↓ = 시즌 성장↓ → `season-check` 재튜닝 필수.

### 4.2 리그를 '인과·서사의 무대'로 (수확)
관전이라도 **"내 결정이 저 장면을 만들었다"** 가 보이게:
- **선수 저니(journey)**: 육성→데뷔전→시즌 하이라이트→성장 을 한 선수의 이야기로 잇는다.
- **경기 전/후 개인화**: 전 "이 경기 주목 선수(=내가 키운 애)", 후 "오늘의 우리 선수 — 캠프에서 토스 70→92 → 결승 세트 포인트 어시스트".
- **마일스톤 모멘트**: 데뷔전, 첫 20득점, 라이벌전 활약 — 그 선수의 서사 노드.
- 이미 있는 장치(데뷔전 배지·컷인 "캠프에서 ___"·캠프의 흔적·통산 기록)를 **더 크게·더 개인적으로** 키우면 된다. → **대부분 연출 계층, 밸런스 무관.**

### 4.3 하나의 목표가 육성을 먹여준다
- 장기 목표 = **내가 직접 빚은 선수들로 리그 우승.** "이 우승 로스터는 전부 내 주인공들"이라는 성취.
- 수집 → 육성 → 리그 → (노화) → 다음 육성 이 **한 방향으로 흐른다.**

## 5. 단계 계획 (밸런스를 한꺼번에 깨지 않게)

| 단계 | 내용 | 밸런스 영향 |
|---|---|---|
| **0 — 수확 연출(먼저)** | 4.2 전부: 선수 저니, 경기 전/후 '우리 선수' 스포트라이트, 마일스톤, 시즌 결산의 "내가 키운 선수들" 서사. **연출·표기만.** | **없음.** 엔진·경제 불변, `season-check` 그대로 |
| **1 — 시간축 분리(구조)** | 3절: 매치데이 풀캠프 → 프리시즌 집중 + 시즌 중 경량 조정. | ⚠ 육성 빈도 변화 → `season-check --app` 재튜닝 |
| **2 — 희소·무게(경제)** | 4.1: 프로젝트 슬롯·재육성 비용/제한. | ⚠ 경제 재튜닝(league-and-economy) |

→ **0단계부터 간다.** 강점(인과·서사)을 밸런스 손 안 대고 먼저 세워서 "리그가 육성의 보상"이라는 느낌을 만든 뒤, 1·2단계로 구조·경제를 맞춘다.

## 6. 열린 결정 (기획자 확인 필요)

1. **프로젝트 슬롯 수** — 시즌당 몇 명을 '빚을' 수 있게? (2? 3?) → 1·2단계 설계의 기준.
2. **시즌 중 육성** — 완전히 없앨까, '경량 조정'으로 남길까? (부상·컨디션 대응 여지)
3. **재육성 억제 방식** — 비용(골드/티켓)인가 횟수 제한인가. → 리롤 그라인드 vs 접근성 트레이드오프.
4. **수확 연출의 밀도** — 매 경기 '우리 선수' 스포트라이트를 띄울지, 마일스톤/주목 경기에만 띄울지(과하면 피로).

## 7. 한눈에

- 정체성: **내가 키운 선수가 리그에서 활약하는 걸 보는 게임.**
- 루프: 스카우트 → **육성(희소·깊음)** → **리그(인과·서사 보상)** → 결산 → 노화 → 반복.
- 시간축: **프리시즌=짓기 / 시즌=겨루기** 로 분리(중복 제거).
- 지금 할 것: **0단계(수확 연출)** 부터 — 밸런스 무관, 강점을 먼저 세운다.
